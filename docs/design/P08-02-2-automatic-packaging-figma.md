## 日常操作与信息层级

默认进入“应用封包”：选择母版或子版 → 勾选功能 → 点击“封包母版/子版”。不再增加旧的连接目标确认弹窗。右侧“本次封包”直接汇总实际选择，窄窗口移到选项下方。版本、运行库、产物目录沿用默认值；提供“递增修订版”“选择文件夹”和运行库按钮，不新增手填项。

“含离线运行库”只改变 WebView 运行库交付方式，不代表业务可以离线接入。母版始终含后台自动部署/同账本同步，子版不含后台；节点安装权限不由“业务数据备份”选框决定。

“开发数据”和“发行维护”是开发版独立页签，不出现在正式版，不作为每次封包的必经步骤。开发者原有认证、兼容性检查和读取能力继续保留；任意来源指允许读取兼容且获授权的数据，不绕过来源保护。正式发行只用已保护的正式站点绑定，不读取当前开发数据源作为目标。

旧 `105:1933`、`108:2120` 中的日常封包目标/账号/文件导入设计由本设计覆盖；旧首次登记页继续仅作历史。开发连接弹窗、离线目录验证、备份读取和现有备份维护细节仍沿用已实现页面，迁入独立开发数据页，不删除能力。

## 权限交互与正式端显示

目录来源保持 `desktop/permissions.json`，不得各层复制不同的权限清单。Figma 提前使用目标名称“业务数据备份”；当前源码仍叫“服务备份”，统一更名由 F 落实。

| ID | 可选范围与联动 | 正式端效果 |
| --- | --- | --- |
| quote | 两版必选、锁定 | 报价与新建订单 |
| orders | 两版可选；关闭时移除 edit_orders / exports | 订单记录与客户匹配 |
| edit_orders | 自动包含 orders | 编辑原订单、追加备注 |
| finance | 仅母版；关闭时移除 prices | 成本、利润、内部财务报表 |
| prices | 仅母版；自动包含 finance | 价格维护，含成本 |
| exports | 两版可选；自动包含 orders | 报价导出、导出记录；财务产物还需 finance |
| settings | 两版可选；关闭时移除 backup | 母版设置，子版只读 |
| backup | 仅母版；自动包含 settings | 主机现有每日业务数据备份操作 |

母子选择各自记忆本轮勾选，不把母版专属权限带进子版。子版画板关闭 settings 是自定义选择示例，不要求更改当前默认值。发行者上限不足的项在开发端禁用并简短说明；正式端没有该项、空占位或“仅母版”说明。

母版业务目录偏好仍为“已保存，暂未应用”，不能更改 Host 目录。没有账户、登录、退出登录开关；这些入口在所有正式版本恒定不存在。隐藏地址/路径也不能通过 tooltip、标题、无障碍名称或原生错误消息泄漏。

## 状态规则

| 状态 | 开发端动作 | 实现要求 |
| --- | --- | --- |
| 尚未开始 | 修改选择、封包 | 不要求当前开发业务连接在线；单独检查发行准备 |
| 发行未准备 | 前往发行维护 | 不能退回手填 connection.json、账号密码 |
| 正在封包 | 只显示实际阶段，可取消 | 固定本次选择；阶段未知时不虚构百分比 |
| 可重试失败 | 重试本次、打开本次日志 | 保护候选 package_id/秘密/摘要；查询原回执，不盲目新发一包 |
| 内容或负载改变 | 新任务 | 新 package_id；不能覆盖原不可变记录 |
| 授权不可用 | 进入维护、打开日志 | 不自动换身份或用旧业务管理员回退 |
| 已取消 | 重新封包 | 已登记未交付包按发行契约关闭；不能展示成功产物 |
| 完成 | 实际产物摘要、打开文件夹 | 只在正式登记与最终负载封装完成后展示，摘要来自本次 manifest |

一次性维护通过 B 的 `automatic-prepare` / `automatic-connect` 能力接入按钮。准备升级包时自动探测本机候选网络接口；多候选时让用户选择接口标签，不要求手填地址。专用升级包在原主机运行一次，接受必要 Windows 授权，随后本机检查并保存正式绑定。未完成、过期、失配分别进入维护反馈；不能用弹窗导入证书替代信任建立。上述按钮接线待 C/D，不是已实现的图形操作。

正式端首次无可用身份时只保留品牌与空白工作区，后台自动重试。已进入工作台后短暂失联保留已授权页面与本机草稿；未决写入锁定相应编辑/提交/清空动作，保留原请求 ID，复核原回执后处理。明确收到权限撤销/变化时必须撤下失效功能，隔离保留草稿，不把草稿重放到其他身份。任何阶段都不显示“未连接”“登记失败”、主从角色、证书或服务地址，不伪报保存成功。
