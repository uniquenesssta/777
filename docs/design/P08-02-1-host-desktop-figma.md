## 设计语义

- 左侧切换在线 Host、数据目录、恢复备份；右侧正式封包目标独立保存。目录读取显示原始来源与工作副本，修改仅留在工作副本。
- 在线 Host 的备份位置为只读设计；隐藏备份的开发者展示需要后续受授权的管理信息来源，不能直接扩展普通业务 API 返回隐藏位置。未取得配置时应显示不可用状态，不推测路径。工作副本的备份配置独立于线上 Host。
- 正式母版只记住业务目录，显示“已保存，暂未应用”；报价表、图片的发布设置继续实际生效。业务目录偏好按本机、账本隔离，不造成业务数据搬迁。
- 正式界面使用业务名称与配置位置别名，不展示 4.23；开发页面显示实际目标地址。真实输入包含需隐藏的地址时仍按现有显示别名规则处理，不能用别名覆盖原值。
- 首次登记文件与 Host 公开连接文件、主机加入文件分开处理。生产运行必须校验权限、有效期和目标身份；原型的成功跳转仅演示导航，不代替上述检查。
- 页面内地址、账本、目录、版本、备份时间均为设计样例，不代表 38 现场同步或业务闭环已通过。
- 27 条主要演示导航覆盖数据源切换、连接/恢复、母子封包确认、登记成功/重选和目录保存。系统文件选择器、实际网络请求、构建、日志打开及错误触发由实现接入，不宣称完整交互原型已验收。
