## 1. 目标与当前缺口

让使用者明确知道当前读取哪套数据、封包后连接哪个 Host、目录设置是否实际生效。减少手工输入地址、证书和指纹，避免临时读取测试数据影响正式封包。

| 项目 | 已有能力与证据边界 | 本任务目标 |
| --- | --- | --- |
| Host 部署 | 已有独立包、一键加入、自启和同账本异步复制；用户表示 Host 先部署，桌面端未安装 | 核对 23、38 现场角色、同账本身份和同步结果；不将部署完成等同同步完成 |
| 开发版连接 | 可手工输入服务地址、PEM 和指纹 | 导入公开连接文件并显示实际连接、身份核对结果 |
| 开发者读取目录 | 当前控制器要求开发用 loopback 服务配置，不能任意打开正式 Host 目录 | 识别在线 Host、离线业务目录、备份，并按来源读取 |
| 封包 | 当前使用选定的单节点连接 | 独立保存封包目标，明确目标服务及账本，阻止误封开发 loopback 地址 |
| 正式端设置 | 已有报价 Excel、图片输出位置；备份位置只读 | 增加业务数据位置的持久化设置，但暂不应用至 Host |
| 设备登记 | 已有一次性登记与设备身份协议 | 衔接母版/子版首次使用流程，提供简短引导 |
| 主备能力 | 38 转发业务至主机并异步保存副本，无自动接管 | 如实展示边界，登记自动切换与接管后续范围 |

## 2. 必须保持的规则

1. 23 现有部署保持不动，不因本任务重新初始化、搬移数据或替换其证书。若后续实现必须升级主机，应先说明具体依赖与保留方案。
2. 目标拓扑为 23 主机、38 同账本同步节点；现场未核对前不登记“38 已同步”。两份独立账本不得自动合并或交替写入。
3. Host 不依赖桌面软件运行；服务电脑不需要开发者版或 SDK。母版/子版安装在实际操作电脑，允许与 Host 同机但不是必需。
4. 正式桌面端通过 Host 读写业务数据，不直接打开服务数据库；“只能查看 Host 数据”指数据来源受限，不取消原有开单、编辑与权限控制。
5. 新部署目录跟随程序包父目录：`Quote777Host`、`Quote777Service`、`Quote777Hidden` 同级。`Quote777Hidden` 是本机普通备份，固定隐藏备份是 `\\192.168.4.23\共享\backup`。角色名称不由文件夹名字或 Windows 属性推断。
6. 仅本机三个 Quote777 顶层目录按既有规则设置 Hidden + System；Directory 为目录固有属性。不递归修改，不修改网络共享属性。现有部署保留其已生效配置。
7. 业务目录、普通备份、隐藏备份、报价 Excel/图片输出目录以及封包输出目录分别管理。同步节点不额外执行主机的输出任务与每日备份。
8. 正式母版设置继续隐藏 4.23 地址，不通过新增目录字段、连接摘要或报错文字泄漏该地址；开发者可查看实际配置。
9. 所有代码按功能职责拆分，无论规模大小；UI 先在既有 Figma 中设计并记录节点，再实现。沿用已确认的紧凑风格，不增加全局提醒条。
10. 日志按每次启动独立目录保存，限量、合并重复事件；不记录密码、登记票据、私钥或完整业务正文。

## 3. 实施任务与验收

### A. 现场状态与操作顺序

- [ ] 收集两台 Host 的状态摘要：角色、账本编号、同步状态、最新完整数据代及节点确认情况。
- [ ] 核对两台账本编号一致；主机与同步节点角色符合预期。独立账本、未加入、落后或不可达必须明确显示，不能自动覆盖。
- [x] 给出可照做的操作说明：Host 就绪 → 开发版导入连接 → 核对业务账本 → 选择独立封包目标 → 用户本地封包 → 逐设备登记 → 安装使用。
- [x] 标明各字段来源，不要求用户猜测证书或把 `D:\Quote777Service` 填进服务地址。

验收：Host 在没有桌面软件时保持运行；说明中的实际状态有现场证据，未收到的证据写“待确认”。

### C. 导入 Host 连接文件

- [x] 接受部署生成的 `777-public-connection-v1` 公开文件，自动填写 URL、PEM、SHA-256 指纹。
- [ ] 校验结构、HTTPS 地址、证书与指纹一致性，再核对服务响应及授权后的账本身份；仅导入文件不等于连接成功。
- [x] 私钥、服务私有配置、`.777join` 加入文件与桌面登记文件不能当作公开连接文件使用；给出针对性错误。
- [x] 导入失败保持原有连接与草稿；切换账本遵循既有未保存草稿、未决提交处理规则。

验收：正确文件可完成可信连接；损坏文件、错误指纹、错误类型与不可达服务不能造成静默切换。日志不包含凭证。

### D. 开发者读取任意位置的兼容数据

- [x] 明确来源类型：在线 Host、本地/移动硬盘/UNC/映射盘的离线业务目录、`.qbackup` 恢复备份。
- [x] 不以盘符或固定目录限制选择；Hidden/System 目录可识别。有访问权限且格式兼容才可读取，“任意位置”不等于任意文件格式。
- [x] 在线 Host 通过服务读取；目录被运行中的服务占用或无法确认一致性时，不以第二个可写进程直接打开。
- [x] 离线目录通过一致性与版本检查后，以独立工作副本接入开发环境；保留源文件，避免改写正式 Host 配置、运行身份及证书。
- [x] 备份恢复到独立目录后读取，不覆盖当前账本；兼容范围及不支持版本有明确结果。
- [x] 明确显示原始来源、工作副本与账本身份。工作副本上的编辑仅保存在副本，本轮不自动回写或合并到源 Host。
- [x] Windows/共享访问权限与业务授权继续有效，不绕过加密、认证或撤销状态；失败不切换当前数据源。

验收：本机、移动盘、UNC、映射盘与 Hidden/System 兼容样本均有针对性 Windows 证据；覆盖权限不足、断连、损坏备份、来源占用和版本不兼容；源数据未被改写。尚未具备的现场条件单独标注，不虚记通过。

### E. 封包目标独立管理

- [x] 开发者“当前读取的数据源”和“正式封包目标”分别持久化，临时切换数据源不更改封包目标。
- [x] 封包前显示发行类型、目标服务、已核对的账本身份、版本和产物位置；密码与设备票据不进入公共安装包。
- [x] 正式目标拒绝 `localhost`、loopback 或仅开发环境可用的连接；证书/身份不一致或未完成目标核对时给出阻断理由。
- [x] 当前正式包继续使用一个节点连接。默认目标按既有决定选择 23；不把“23 → 38”展示为已实现的自动切换。

验收：读取另一份测试数据后封包目标仍保持；母/子版类型及权限边界保持；用配置与协议级检查验证，不重新安排用户已取消的 Windows 母子版构建准备、安装包验证或远端测试包下载。

### F. 正式端业务数据位置设置（保存但不应用）

- [x] 正式母版提供“业务数据保存位置”输入、选择目录和保存；只保存用户配置值，不探测或搬迁 Host 真实目录。
- [x] 保存到当前电脑的本地偏好，按账本隔离；重启后保留，不同步为服务端配置。子版延续既有权限原则，不新增管理员设置权限。
- [x] 页面就近显示“已保存，暂未应用”；不提示“业务数据已迁移”或“已切换”。未提供应用功能前不显示可执行的应用按钮。
- [x] 不修改 Host 的服务配置、每日备份计划、主从关系或真实数据根；不自动创建数据库，不因填入不可达目录影响开单。
- [x] 与报价表、报价图片的实际生效设置明确分开；地址隐藏规则作用于显示层，不能用显示别名覆盖保存的真实输入。

验收：填写、保存、重启读回成功；保存前后订单仍写入同一 Host/账本，服务配置及备份目标不变；原有报价输出设置继续生效。母版可编辑、子版权限不扩大。

### G. 正式设备首次登记

- [x] 复用已有每设备一次性登记机制，将母版/子版首次接入做成简短引导；登记成功后持久化设备身份，日常不重复登录。
- [x] 明确区分 Host 加入文件、公开连接文件和桌面设备登记文件，按用途导入。
- [ ] 检查登记目标账本、发行角色、有效期、已使用、撤销及换机情况；不能复用同一票据给多台电脑或让子版取得母版权限。
- [x] 补齐管理员增补、撤销设备与重新登记说明；不在任务书或仓库保存真实票据。

验收：有效登记成功、重启复用身份；过期/重复使用/角色不符/撤销均有明确结果，不降级为未授权访问。

### H. 正式启用前的业务闭环

- [ ] 由用户在现场安排一笔明确标识的测试订单，完成新增、修改并核对修改前后差异。
- [ ] 导出报价 Excel、内部财务报表，核对金额、订单归属及实际保存位置。
- [ ] 生成主机普通与隐藏两处备份，核对可恢复文件和可阅读 Excel；Excel 按既定月分页、日分组规则。
- [ ] 将备份恢复至独立目录，核对订单、明细和金额，不覆盖正在使用的数据。
- [ ] 确认 38 收到包含该订单的完整数据代；恢复结果、主机保存成功与副本同步成功分别记录。

验收：订单 → 修改 → 导出 → 双位置备份 → 独立恢复 → 同步核对都有实际证据。网络可达、HTTPS 响应或同步代号单独出现，不能代替业务数据核对。

已勾选项表示源码/文档已接入。[Windows 隔离功能检查已通过](../verification/P08-02-1-windows-checks.json)，不替代各节末尾的现场验收，也不表示实际移动盘、极端长路径和全部现场 ACL 已验证。连接身份兼容及销售登记独立账本比对未勾选，详见实现记录。
