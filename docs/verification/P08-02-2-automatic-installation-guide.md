# P08-02-2 自动安装操作顺序

本说明对应 P08-02-2 A–G 源码流程，尚未执行现场安装；最终封包由用户本地进行。旧版“选择连接文件、导入登记、手工加入 Host”的步骤不适用于新包。

1. **开发电脑只准备一次发行授权。** 使用 `npm run dev` 打开开发版，进入“开发部署 → 发行维护”，选择“准备主机升级包”。如果显示多个本机网络接口，只需选择当前内网接口。软件自动打开专用升级包位置。
2. **原 4.23 主机执行一次专用升级。** 运行升级包入口并接受必要的 Windows 授权，保留已有账本、证书、任务账户和备份。回开发电脑点击“检查准备结果”；显示“发行准备完成”后返回封包。升级包应及时使用；过期或准备失败可重新准备。日常安装人员不做这一步。
3. **选择封包。** 在“应用封包”选择母版或子版、勾选功能，点击封包。版本、运行库、输出目录有默认值及选择按钮，不需要填目标主机、业务账号或导入文件。失败可重试本次任务，沿用原包；内容变化则新建任务。
4. **分发并正常安装。** 使用本次产物中的安装器或 `install.cmd`。母版安装会请求必要 Windows 授权并自动安排后台；子版仅安装客户端。无需安装开发环境，无需共享 Quote777 三个文件夹，无需每台导入登记材料。
5. **自动连接和同步。** 两版业务连接固定 4.23；新母版电脑后台加入同一账本，4.23 本机母版复用原服务。主机暂时离线时静默等待和重试，不能把安装成功当作登记或同步完成。关闭业务窗口不停止后台，重启由开机任务恢复。

| 安装位置 | 母版行为 | 子版行为 |
| --- | --- | --- |
| 4.23 原主机 | 核对后复用原服务，不创建自己的从机 | 独立客户端 |
| 4.38 或其他电脑 | 自动部署同账本副本，业务仍读写 4.23 | 独立客户端，没有 Host |

开发版“开发数据”仍可读取获授权的兼容在线服务、离线目录工作副本及 `.qbackup`；目标来源需要原管理员证明时仍会验证来源。它不改变发行站点。正式端保存的业务目录偏好仍为“暂未应用”，不能重定位后台账本。

新后台默认三个同级目录位于 `%ProgramData%\Quote777\`；已有部署沿用有效位置。`Quote777Hidden` 为本地普通备份，固定共享路径为主机隐藏备份。普通使用者不再填写这几个路径；三个顶层目录设置 Hidden、System，子目录不递归改属性。

有凭据的同角色升级保持设备、销售主体和未决请求；手工删除密钥或更换系统不自动认回原身份，需要维护处理。母版副本不支持自动接管，4.23 离线时不能由 4.38 自动继续开单。同步结果应通过独立 Host 维护工具的真实状态和数据代核对，不能用安装完成替代。

正式母版、子版及母版随附后台不生成根目录 logs 文件，界面也没有日志、登录/退出或技术故障入口。开发版与独立 Host 维护工具保留问题日志：每次运行一个目录，通常提供该次 runtime.jsonl；达到 4 MiB 才轮转，最多两份旧文件。同根目录的子进程合并，独立根目录用 execution_id 关联。

“业务数据备份”沿用每日可恢复数据和可阅读 Excel，按月分表、表内按日组织。未完成、失败或尚未确认时不显示状态、成功时间或结果提示；后台约每 2 秒检查待补写位置，恢复后自动补写原快照，只补尚未成功的目的地。重启后从原进度继续，不重复生成 Excel；实际检测和补写耗时取决于 Windows 共享访问及文件大小。正式端不暴露隐藏路径、错误或问题日志。

封包取消时，未交付授权会进入开发电脑的持久关闭队列。主机离线可先退出，下次打开开发版会继续关闭同一授权；失败任务若选择重试，则保留原候选。此行为不要求使用者寻找或填写额外文件。

4.23 的主 Host 后台须持续运行，关闭桌面窗口后仍运行，重启由已有开机任务恢复。各客户端的业务写入由同一主后台统一保存；38 等母版后台只同步副本。局域网中断保留草稿和原未知请求，不在各机生成独立正式订单后自动合并；恢复后的备份补写、节点副本同步是后台任务，无需另部署一层合并程序。
