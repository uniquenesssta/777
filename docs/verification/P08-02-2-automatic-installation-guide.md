# P08-02-2 自动安装操作顺序

本说明对应 P08-02-2 A–G 源码流程，尚未执行现场安装；最终封包由用户本地进行。旧版“选择连接文件、导入登记、手工加入 Host”的步骤不适用于新包。

1. **开发电脑直接封包。** 使用 `npm run dev` 打开“开发者工具 → 应用封包”，选择母版或子版、勾选功能，点击封包。签发身份自动保存在本机；4.23 离线也不阻挡封包。版本、运行库和输出位置均通过现有选择按钮完成，不填业务账号、密码、目标主机或连接文件。
2. **已有 4.23 只做一次普通 Host 软件更新。** 在同一开发电脑运行 `npm run package:host` 生成配套 `Quote777Host.zip`，由后台维护者在 4.23 原部署位置使用该包运行 `deploy.cmd`。保留原账本、业务证书、账户、备份和任务所有者，自动配置新包识别能力。这个维护动作可以在封包前或后做；没有“返回开发电脑完成授权”的步骤，也不随每个安装包重复执行。Host 包只给后台维护者，包含首次接入服务私钥，不能随桌面安装包公开分发。
3. **分发并正常安装桌面包。** 使用本次产物的安装器或 `install.cmd`。母版自动安排本机后台；子版只安装客户端。必要的 Windows 系统提权保留，不要求填写业务账号或找连接/加入文件。
4. **软件后台自动接入。** 服务器核验签名包的版本、角色和勾选权限，返回真实业务账本及原业务证书。母版另行加入同账本同步节点，已有 4.23 主机继续复用。服务器暂时离线时静默等待；初次等待不等于已绑定或已同步。关闭业务窗口不停止后台，开机任务负责恢复。

| 安装位置 | 母版行为 | 子版行为 |
| --- | --- | --- |
| 4.23 原主机 | 核对后复用原服务，不创建自己的从机 | 独立客户端 |
| 4.38 或其他电脑 | 自动部署同账本副本，业务仍读写 4.23 | 独立客户端，没有 Host |

开发版“开发数据”仍可读取获授权的兼容在线服务、离线目录工作副本及 `.qbackup`；目标来源需要原管理员证明时仍会验证来源。它不改变发行站点。正式端保存的业务目录偏好仍为“暂未应用”，不能重定位后台账本。

新后台默认三个同级目录位于 `%ProgramData%\Quote777\`；已有部署沿用有效位置。`Quote777Hidden` 为本地普通备份，固定共享路径为主机隐藏备份。普通使用者不再填写这几个路径；三个顶层目录设置 Hidden、System，子目录不递归改属性。

有凭据的同角色升级保持设备、销售主体和未决请求；手工删除密钥或更换系统不自动认回原身份，需要维护处理。母版副本不支持自动接管，已满足 P08-02-3 D 登记和租约条件的客户端可本机正式入账并静默续传，不能将副本提升为主机。同步结果应通过独立 Host 维护工具的真实状态和数据代核对，不能用安装完成替代。

正式母版、子版及母版随附后台不生成根目录 logs 文件，界面也没有日志、登录/退出或技术故障入口。开发版与独立 Host 维护工具保留问题日志：每次运行一个目录，通常提供该次 runtime.jsonl；达到 4 MiB 才轮转，最多两份旧文件。同根目录的子进程合并，独立根目录用 execution_id 关联。

“业务数据备份”沿用每日可恢复数据和可阅读 Excel，按月分表、表内按日组织。未完成、失败或尚未确认时不显示状态、成功时间或结果提示；后台约每 2 秒检查待补写位置，恢复后自动补写原快照，只补尚未成功的目的地。重启后从原进度继续，不重复生成 Excel；实际检测和补写耗时取决于 Windows 共享访问及文件大小。正式端不暴露隐藏路径、错误或问题日志。

新封包取消只终止本机任务，不需要连接 4.23 关闭尚未登记的授权。旧在线发行任务仍按原关闭队列恢复；已登记包的撤销由 Host 所有者维护处理。失败重试保留原签名候选，内容变化则新建封包任务。

4.23 主 Host 必须持续运行，关闭桌面窗口后仍运行，重启由已有任务恢复。它接收并统一处理客户端数据；共享 backup 目录只用于备份。离线正式订单与冲突处理进度以 P08-02-3 为准，E 母版业务核对仍暂停。本次没有执行现场升级或最终 Windows 安装包验证。
