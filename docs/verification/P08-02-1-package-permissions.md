# P08-02-1 追加：选择式封包与正式端静默界面

根据用户最新要求，正式端取消账户菜单、登录、退出、登记引导及内部连接提示。本节覆盖早期“正式端首次登记页面”的交互要求；设备登记协议仍保留，由安装部署入口准备身份。

## 操作方式

开发部署 → 应用封包：选择母版或子版 → 勾选功能 → 选择当前已连接 Host 或已核对的独立目标 → 选择输出文件夹、联网/离线安装 → 确认功能清单并封包。版本号可点击递增，不必输入配置路径或修改源码。重新选择其他 Host 时仍须核验管理员身份，不绕过认证。

| 选择 | 母版 | 子版 | 关联规则 |
| --- | --- | --- | --- |
| 报价、新建订单 | 基础功能 | 基础功能 | 保持可用工作台 |
| 订单记录、客户匹配 | 可选 | 可选 | 受 Host 原有订单归属限制 |
| 继续编辑、追加备注 | 可选 | 可选 | 需要订单记录；作废/恢复仍仅管理员 |
| 成本、利润、内部报表 | 可选 | 不可选 | 实际导出还需导出权限 |
| 价格维护 | 可选 | 不可选 | 涉及成本，联动财务权限 |
| 导出报价、导出记录 | 可选 | 可选 | 需要订单记录 |
| 存储设置 | 可选 | 可选，只读 | 母版保留本机业务位置偏好，仍不改变 Host 位置 |
| 服务备份 | 可选 | 不可选 | 需要存储设置 |

两种正式版本都不提供账户入口。未配置身份时仅显示品牌和空白工作区；连接失败在后台每 15 秒重试，不弹出技术错误、服务地址或重新登录提示。已录入草稿保留；未知保存结果通过原请求 ID 查询/重试，未取得回执不会显示保存成功。合法业务确认和输入核对保留。

产物增加 `install.cmd` / `install.ps1`：部署人员双击入口，新设备选择管理员提供的一次性登记文件；已有设备身份继续保留。这不创建账户或共享票据，也不取消登记期限。正式应用本身不提示选择登记文件。

## 实现边界

- 共享功能定义 `desktop/permissions.json`。选择依赖在 UI 与打包校验中一致，选定清单编译到原生安装包元信息，并记入交付清单；前端不能提交新权限覆盖包内策略。
- 原生 IPC 在发出业务请求前限制动作；文件选择器、重试导出、打开导出目录、旧待处理请求的重发均覆盖。Host 继续负责身份、管理员/销售及订单归属。本次没有把旧 Host 协议升级成服务端细粒度设备授权；包内策略不能替代服务端或 Windows 文件 ACL。
- 无财务权限时，返回 WebView 前递归剔除成本、利润、金额展示派生值，清理历史差异中的成本/利润/K 行；价格目录按公共最终单价呈现。财务导出记录被过滤，直接提交历史财务任务 ID 也不能打开或重试。
- 为兼容旧 Host 的 offset-only 导出列表，受限母版在原生层分页扫描，返回可见记录和下一页标记，不泄漏隐藏记录数量；扫描有明确上限，超限记日志并停止，不伪造完整结果。
- 较宽权限版本留下的编辑草稿，在权限缩小时单独保留，本版不显示或自动转成一笔新订单。
- 内部失败继续使用原有按启动分目录、重复合并的日志；不记录票据、密码或完整业务正文。技术原因仅进入日志，业务界面不展示错误码。

## 检查范围

本轮 TypeScript、Rust 单元（19 项）及 Clippy、Node（42 项）、Python（44 项通过，8 项 Windows 专用跳过）、浏览器全量（38 项）均通过。浏览器使用隔离测试账本和桥接模拟；另编译 Linux 辅助验证桥，不是产品安装器。结果见 `P08-02-1-package-permissions-checks.json`。这些检查不代表 Windows/DPAPI/安装器验收。

按用户要求未构建或验证 Windows 母版/子版安装包，也未操作 23/38 的真实服务、真实数据或登记票据。Windows 安装入口需要用户后续本地安装时确认；旧 Host 身份核对兼容缺口及现场同步验收状态沿用既有记录。
