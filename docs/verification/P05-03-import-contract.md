## 导入边界

[quote_import](../../quote_import/__init__.py)读取显式选中的文件，不枚举目录。所有金额由已验收quote_core重验，不建立新计算公式，不按当前价格修正历史；相同来源哈希/适配版本只提交一次。来源、预演SHA、归属和隔离选择绑定后才能提交；源文件变化须重新预演。JSON客户/淘宝ID不作账户，归属必须由管理员显式选择现有账户，作为归档保管人；历史操作员未知，不伪造作者。

| 来源 | 自动识别与处理 |
| --- | --- |
| identified-v1，含完整UUID/状态/回执 | 校验关联/价格版本/规则，按原稳定订单分别导入；同秒同客户不合并 |
| tagged-v1，无稳定编号 | 只用明确总计边界或唯一单行前缀；不清楚的记录隔离 |
| legacy-26、用户别名、字段重排、备注列、缺摘要 | 复用已有列映射/读取规则；逐行核心对账，原输入缺失时显式记规范值替代来源 |
| 两个同秒记录、缺编号和总计边界 | 隔离，不能按客户/时间猜合并或默认为一单 |
| items JSON、旧价格字典 | 保存历史PriceVersion，不替换active价格或母子目录；旧字典必须显式给单件名单，空名单表示全为面积 |
| 公式（含已有缓存）、宏/外链/图形扩展、未知表/坏ZIP | 整来源隔离；不评估公式、不信公式缓存、不启动外部程序 |
| 金额/规范字段/折扣系数/折前金额与核心不同，或未知规则版本 | 独立差异报告，不修改原成交值；通过部分只在显式认可隔离结果后提交 |

26列空账本只证明0单识别与附表保留。P01实际材料仅有已核对的空账本结构摘要，本轮对应样例为合成重建，不宣称真实成交或历史迁移通过；真实旧格式存在性仍未知，首次出现需只读识别、副本对账。

## 事务、映射与恢复

继续使用ledger-v1的ImportBatch表和原DDL，不自动覆盖或升级旧库。每来源在一个BEGIN IMMEDIATE事务内创建历史价格、订单、明细、备注、回执、审计和批次；中途错误整批回滚。所有财务快照仍满足原库存完整性验证，价格不成为当前发布版。

映射保留原订单/明细编号、源表/行→新订单/明细/备注ID、原版本、状态、事件、原输入、价格及原始源文件完整字节。完整字节以base64保存于受保护SQLite的ImportBatch元数据，校验SHA与不可变回执；备份/独立恢复可重新核验。文件级最近备注和无法归属的输入诊断留作文件证据，不自动挂到最后客户。

已编号订单的新文件哈希若内容相同则复用原ID；内容/归属变更拒绝覆盖。无编号历史的新哈希若与已有记录相似，则拒绝并要求核查，不自动合并或再次记账；同一文件内有明确边界的相同订单仍分别保留。新归档订单初始revision=1，原revision和事件单独保存；作废状态保留，只有active进入有效汇总。无时区时间按UTC+8解释并保留原文；没有可解析时间不能猜日期。未知提交使用由来源/版本生成的原batch request_id核查和原请求重试，不新建ID。

容量：显式来源最多20MiB；价格JSON沿用1MiB；ZIP最多2048成员/64MiB展开、无重复成员；工作表最多50000行/64列/100万覆盖单元格，拒绝实体/不支持编码。过大或未知输入清楚失败，不输出“正常零金额”。公开预演只含数量、允许的金额字符串和隔离位置；客户、原件、完整计划留`private`目录，Windows使用现有Hidden+System和受保护DACL，不能把private发给他人。

## 后续显式管理入口（当前不要求执行真实导入）

[p05_import.py](../../tools/p05_import.py)默认先预演。以下为操作格式；文件/目录由操作者选择，不固定旧E盘位置：

```powershell
py -3 tools/p05_import.py preview --source '所选副本.xlsx' --output reports/p05-preview-01
py -3 tools/p05_import.py apply --source '所选副本.xlsx' --review-sha256 '预演给出的SHA256' --host-root '本机主机目录' --username manager --owner manager --output reports/p05-apply-01
```

apply限实际Windows本机管理员，密码不回显、不放命令参数/报告；核对现有启用的保管人账户。入口持有与HTTPS主机相同的service-owner锁，运行中的主机拒绝；必须先完成已验证的完整服务维护备份，失败不写入财务。隔离结果需要认可时追加`--allow-quarantine`，旧JSON单件策略通过`--legacy-single`给出。首次正式迁移仍在副本演练和P08切换流程内，不自动接入生产。

本轮接口为本机管理CLI与可信内部Python导入器，未新增客户端任意文件路径上传接口。原服务客户端/Excel流程及计算源码保持；报表/附件任务、Tauri页面接入在后续阶段实现。保存报告失败不把已提交订单说成未提交，控制台保留原请求ID与真实提交状态。
