## 开发电脑怎么使用

1. 在Windows准备原项目要求的Node、Python、MSVC/Windows SDK、锁定Rust工具链和字体；从仓库执行 `npm run dev`。
2. 自动进入开发版后打开顶部“开发部署”。“存储位置”选择主机账本根目录；“读取此位置”读取已有兼容账本，“新建空账本”在明确选定的空数据目录初始化，备份目录可已有其他文件。第一次读其他账本时验证该账本自己的管理员，绝不重置原密码。新空账本可直接进入价格维护并添加首个商品；已记住密码失效时可以重新验证。
3. 选择“备份位置”和开发者专用“隐藏位置”，设置北京时间的每日整点，再点“保存备份设置”；保存只更新设置，不立即固定当天快照。两处都可选择已有其他文件的目录，原文件和属性保留，但不能指向同一实际目录。每天生成同一快照的`data.qbackup`恢复文件和`data.xlsx`阅读文件；手动“生成今日备份”会提前固定当天快照，重复操作仅补写同一份。使用“导入备份”选择`.qbackup`及新的空存储目录，导入并读取后核对业务数据，原账本保留。旧备份不自动删除。
4. 设置版本、输出目录及安装方式，点击“一键封包母版”或“一键封包子版”。源码须已提交且工作区干净；输出位置支持本机、共享、映射盘、移动盘及可解析目录链接，也可选在源码目录内。每次在所选位置新建角色/版本/任务ID子目录，成功后可打开产物目录；已生成的安装包不会干扰后续封包的源码检查，真实源码修改仍须提交。

无需下载CI重复测试包。本机生成exe、NSIS安装包、release.json、公开连接配置、登记脚本与许可文件。联网安装包在目标机缺少WebView2时需要联网；离线完整包包含运行时，通常较大，界面以本次实测大小为准。设备登记仍遵循P07-04既有流程，本项不引入共享授权密码。

## 保存位置和受支持边界

- Windows开发配置在 `%LOCALAPPDATA%\Quote777Development\developer.json`；其他账本的管理员凭据按当前Windows用户DPAPI保护，独立保存于 `developer-credentials.bin`，不进入前端状态、Git或安装包。
- “存储位置”指完整兼容的quote-host账本根目录，不是单独SQLite文件、客户端profile或任意历史文件夹。当前开发启动器管理本机127.0.0.1:18477；已有目录必须符合该绑定且未由其他进程占用。远程正式服务通过既有“连接设置”读取。P08另行处理真实主机部署/历史迁移。
- 读取时验证身份、版本和资源；必要的兼容资源更新沿用`select-host --upgrade-resources`核对链路，不额外生成完整备份。P07-06追加支持本机盘、共享UNC、映射盘、移动盘和可解析目录链接；保留未知非空数据目录的防覆盖校验，不自动搬移数据。切换成功清除旧会话/计算/查询缓存，重新加载业务；按证书标识分开保存原始草稿。未知提交在原生层阻止切换/变更备份位置。
- 改目录与备份操作是有界维护操作，期间阻止关闭；封包在启动器后台执行。私有端口随机且仅绑定loopback、令牌不进入前端、拒绝浏览器Origin；IPC只能发送固定操作。封包进程先等待私有启动管道，纳入Windows Job后才运行；取消/父进程退出关闭Job，回收全部构建后代。失败产物不能显示为成功。
- 若重启时已保存的账本目录被移除、凭据失效或配置损坏，启动器明确失败，不静默切回其他账本。恢复该目录/管理员访问后重开；当前不提供离线账本修复界面。
- 正式manager/sales前端编译移除开发页；原生开发枚举只在无交付/verification特性的debug构建存在。测试窗口参数仅debug或verification编译，正式release无此能力。
