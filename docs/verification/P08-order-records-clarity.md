# 订单记录：高光与客户／订单区分（2026-10-20）

## 原因与实际变化

旧列表将 `app.selected`（最近查看、保存或编辑的订单详情）当成列表选中状态，整行使用紫色背景。它不是固定首行，也没有对应的列表选择操作。本次移除该展示绑定和样式，保留详情对象本身，详情与继续编辑照常工作；仅悬停时使用中性浅灰背景。

- 全部订单保留服务排序和分页，每笔订单有底部分隔线，订单号突出，客户／淘宝 ID 下显示微信号。状态仍有已保存／已作废标签，不与整行选择混淆。
- 按客户查看以真实 `group_id` 分卡片，顶部显示客户与微信身份、订单数、有效订单数及有效订单合计；内部表格明确订单号、创建时间、应收金额、状态和操作。客户间有独立边框与间距，订单间有行分隔。同名不同身份不在前端合并。
- 查询、客户与组内订单分页、查看、继续编辑、该客户新建订单使用原有业务方法；作废订单不提供继续编辑，子版依封包权限不提供编辑与利润信息。
- 长客户名称及微信号可换行；窄窗口表格在卡片内横向滚动，状态与操作不通过压缩列宽挤没。无业务会话时客户页保留但不发起无身份查询。
- 按职责拆分客户查询 hook、报价匹配、客户身份、客户卡片、组内订单表和订单记录专用样式；不改变服务协议、客户匹配规则、账本存储或同步流程。
