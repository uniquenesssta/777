# P08 本机导出与详情页连续适配

2026-10-21（北京时间），以本轮最新纠正为准。

- 母版恢复报价表、报价图片和内部财务报表入口，仍受原封包权限控制；子版继续隐藏。开发版保留。
- 详情页取消 900/600 高度断点切换排列，尺寸与间距连续适配；整页、左右卡片不滚动，只有长商品列表内部滚动。记录入口仍在底部。
- 存储与备份只选一个本机根目录，自动创建 `PIC`、`Excel`、`内部财务报表`，选择后直接保存本机配置。后续改目录无需重新封包；不修改 Host 保存位置。子版不展示内部财务报表路径。
- 新导出只向当前账本发出读取请求：校验订单版本，在桌面端生成真实 PNG/XLSX，校验文件并发布到本机目录。期间报表使用版本绑定的分页读取，末尾再核对视图，数据变化则拒绝混合快照。大范围报告在本机 SQLite 临时数据库中分批，保留按月/按日内容和金额历史格式。
- 新导出记录、不可变输入快照、失败重试和删除失败记录均在本机。旧服务器导出记录/文件原样保留，不自动搬迁或删除；新版导出记录展示本机新记录。历史成功导出的打开位置保持原位置，改根目录只影响后续生成。
- 输出文件发布前核对大小、摘要、类型；已有同名文件被手工修改时保留原文件并报错。目录创建失败不覆盖旧设置。
- 中文 PNG 使用随桌面端分发的固定版本 Noto Sans SC 字体，验证字体摘要；不再读取服务器字体配置。故障日志记录本机任务 ID、类型、错误码，不写商品内容。
- 业务数据自动保存、备份、同步以及 Host 代码保持不变。本轮不需要重新生成 Host。

## 日志结论

`runtime(10).jsonl` 明确记录 `OpenOutputFolder -> OUTPUT_FOLDER_ON_HOST`。这是打开服务器内部路径失败，不能作为 PNG 渲染失败的证据。`CreateOutput` 请求成功，但该日志未记录任务级图片失败码，因此历史图片失败的确切根因未确认。新流程实测能生成含中文的 PNG，并补齐本机任务失败诊断。
