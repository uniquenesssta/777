# P08 允许清空商品后发布价格版本

用户要求：价格维护删除全部商品后仍可提交新版本，不必留下一个商品；没有历史版本时也可首次发布空目录。

## 实现

- 价格维护允许 0 个商品进入发布确认，空目录确认文案明确保留订单和历史价格。未填完的商品行仍不可发布。
- Host 接口与 Rust 配置解析同时接受显式 `items: []`，账本仍创建真实版本、更新当前版本、保留发布序号、事务和并发版本检查。
- 旧配置的空对象、格式错误、无效商品和容量超限仍拒绝；Python 基准配置解析同步相同规则，保持对照一致。
- 清空不删除历史版本或订单。报价工作台原有逻辑在空目录时禁止新增商品；旧草稿仍受价格版本检查，不能按已删除商品继续核价。

## 验证

- 静态检查：TypeScript、Clippy（警告视为错误）、Rust 格式、diff 检查通过。
- 构建：辅助环境 Rust Host、账本和桌面 verification 调用程序 debug 构建通过；Vite 前端构建通过。字体未下载，使用系统字体，此项不作为完整封包构建。
- 自动测试：Rust 核心 29 项通过；Host 价格发布 2 项通过；Python 配置对照 19 项通过。覆盖首次空版本、清空、重试幂等、并发过期拒绝、历史订单保留、备份恢复、恢复后空目录可读及重新添加商品。
- 新增原生浏览器回归 `desktop/tests/ui/empty-prices-native.spec.ts`，连接真实桌面 IPC 和 HTTPS Host，验证删除、空发布、重新读取及重新添加。当前环境浏览器下载返回损坏压缩包或 503，未执行页面点击测试，不计为通过。
- 辅助环境真实桌面 IPC → HTTPS Host：清空、读取、桌面和 Host 双进程重启、再次读取空版本、重新发布商品、发布序号递增全部通过。使用本轮 Rust debug 程序的去调试符号副本，仍执行真实 TLS、认证、数据库和版本校验。首次未去符号的大体积 debug 程序超过测试夹具 15 秒启动时限；未改超时门槛，去除调试符号后重跑通过。
