# P08 导出交互、原订单号与 JPG

2026-10-21（北京时间）。后续纠正，覆盖 P08-local-exports 中 PNG 格式与按钮名称部分。

- 报价表、导出图片、内部财务报表在点击后保留当前页；导出记录仍由用户主动进入。期间 Excel 原本在导出记录创建，仍留在原页。
- “报价图片”入口与类型显示统一为“导出图片”。根目录说明仅为“选择后自动保存。”
- 记录显示输入的原订单号，点击使用真实 order_id 打开订单；未填订单号时明确显示未填写。旧本机记录从原不可变快照读取订单号，不拿任务 ID 或截断 UUID 冒充订单号。期间报表显示日期范围。
- 新图片为真正 JPG（800 像素宽、灰度、质量 60、优化 Huffman），保留原文字内容与固定中文字体。历史成功 PNG 不改动，旧失败图片重试生成 JPG。内部类型键 quote_png 保留兼容，不代表输出扩展名。
- 新增固定 jpeg-encoder 0.6.1（无传递依赖），MIT/IJG 声明在根与桌面 notices 收录，桌面依赖清单同步。使用纯 Rust 编码器，避免新增系统编码服务。
- 真实 IPC/HTTPS 样本 JPG 12399 字节（约 12.1 KiB），Pillow 解码确认 JPEG/800/L；人工查看中文与金额可读。样本体积不代表所有长订单都低于 27 KB。
- Host 仍只有业务读取；堵住服务器导出目录，三类本机导出仍成功，服务器导出任务数为零。Host 代码无改动。
