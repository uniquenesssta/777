- 封包目标独立持久化：公开连接与已核对账本存入本机原生存储，管理员会话仅在内存中；重启需重新核对目标。读取测试数据不会改目标。封包前再次核对账本；原生边界与封包入口均拒绝 loopback。增加目标、账本、发行类型、版本、产物位置确认弹窗。
- 正式母版业务目录偏好：本机 DPAPI 文件按真实账本 UUID 分开，原子替换；输入仅作偏好，不探测路径、不创建目录、不调用 Host 设置/迁移。页面“已保存，暂未应用”，子版不增加权限。地址别名只用于显示，保存原始输入。

- 离线目录：`export-offline` 在已有 owner 锁上确认未占用；Windows 对所有源数据库/边车及输出文件持有禁止写入和删除的只读句柄，先复制到临时受保护目录，在副本上验证管理员及数据一致性，再输出逻辑备份。源数据库不被 SQLite 打开，不复制执行程序、私钥、设备票据至最终工作副本。恢复创建独立目录、新证书及身份，不继承线上隐藏备份路径。当前目录无 owner 记录时拒绝猜测，改用该来源导出的 `.qbackup`。
- 文件选择器显示隐藏目录。离线读取支持底层允许的本地/UNC/映射盘位置；源码没有固定盘符限制。实际移动硬盘、断连和现场 ACL 的证据仍待补齐。
- 管理员设备工具直接读取 Host `connection.json`，可签发、列举、撤销设备。首次登记不再要求使用者寻找 profile 文件夹。

## 兼容边界

新 Host 的授权 `/v1/capabilities` 响应增加 `ledger_id`。旧 P08 主机通过现有管理员 `/v1/cluster/peers` 只读查询取得身份，23 无需为这一查询重部署。

**旧同步节点拒绝 `/v1/cluster/*`，且其能力查询转发至旧主机，不能单靠该节点核对账本身份。** 连接与业务访问仍可使用原协议；目录偏好、封包目标核对遇到此情况显示身份不可用，不能用地址/证书冒充账本 ID。本轮默认仍应核对 23；未升级 23，不宣称任意旧节点均已支持新功能。

登记继续校验发行角色、安装包绑定的地址/证书和服务端票据；旧协议没有供销售设备独立读取账本 UUID 的响应，因此“销售设备登记时独立再次比对账本 UUID”尚有协议缺口，不能等同于封包时管理员已核对。未替用户升级现有主机。

离线导出目前以 512 MiB 源文件总量及 256 MiB 逻辑备份上限拒绝过大来源，不静默截断；来源一致性/权限无法确认时不切换。副本不回写、不合并正式账本。自动连接多个 Host、自动接管仍未实现。

## 2026-10-20 高度自适应与开发连接身份

报价页原先依赖 748px 最小卡片和 458px 商品区；利润、导出、存储与发行维护则按内容高度结束。新增独立 `layout/viewport.css`，根容器使用动态视口、导航参与正常布局；主区按剩余空间伸缩并在矮窗口滚动，列表占用卡片剩余高度，导出分页移到列表外。利润图表用 ResizeObserver 同时测量宽高，SVG 不再反向撑住容器，缩小时重新计算坐标。保留内容最小可读高度和小窗口滚动，不隐藏底部操作。

开发连接表单只提交公开连接信息，移除账号/密码字段和手动填写说明。原生使用已验证、按地址及证书绑定的保护存储身份；首次远程连接沿用用户选定的兼容默认账号和密码。本机开发启动器仍使用其原有随机身份。成功连接后记住身份，重新启动自动接回已选 Host；过期会话只续接一次，并校验原主体和角色，保留计算和待确认请求的原 ID。待确认请求不能通过更换账号转给另一主体。默认密码属于开发兼容默认值，不视作秘密，不编译进 manager/sales 发行分支；正式端设备认证不改动。默认身份若不适用于一个未授权 Host，仍由真实服务器拒绝。

既有 Figma 连接稿与相关高度约束已同步，见[设计映射](../design/P08-02-1-host-desktop-figma.md)。最新部署数量及 E 的母版业务核对/不可抹去历史要求记入任务书，本轮没有实现 E 或新增正式端权限。
