# P03-03 连接、目录与价格保护

P03-02已依据用户“开始03”[收尾](P03-02-acceptance.json)。P03-03继续在`stage/p03-file-safety`实施；本页是当前Python过渡契约，不代表Rust、服务或安装包已交付。

## 设置及继承

| 文件 / 来源 | 内容 | 谁能在界面保存 |
| --- | --- | --- |
| `%LOCALAPPDATA%\QuoteProfitCalculator\manager-settings.json` | schema=`777-local-v1`、data_root、backup_dir | 当前母版用户；备份目标只登记 |
| 同目录`sales-settings.json` | schema、data_root、空backup_dir | 当前子版用户，仅选择连接来源 |
| 所选数据源根目录`storage.json` | schema=`777-shared-v1`、price_file、export_dir、screenshot_dir | 母版；子版只读继承价格和输出位置 |
| 上述price_file指向的价格JSON | items及原商品单价/K/单件标志；旧字典也可读取 | 母版显式保存价格；目录保存不改它 |

本机设置按当前系统用户和母/子角色分开，启动先恢复，再加载价格/列表。Windows缺少LOCALAPPDATA环境变量时使用当前用户AppData/Local；辅助环境路径不是Linux产品交付。首次未配置打开Excel记录页的连接设置，不访问旧E盘或UNC。旧常量仅供“选择旧版目录”按钮填入，必须保存连接才使用；“导入旧JSON目录”仅填入可见字段，须核对后保存共享目录。

所有路径在界面可见。母版可编辑价格文件、Excel、截图及本机主机备份登记；子版可选择同一共享源的UNC连接，价格文件和输出目录只读，不能发布覆盖。子版连接选择不提供服务鉴权，成本隔离仍属P05。报表/截图字段未保存时不改变正式输出目标；刷新列表及正式输出前重读storage.json，不隐式刷新草稿价格。

共享位置优先发布相对数据源根的路径。母版`D:\共享根\storage.json`发布`订单\新位置`时，子版通过`\\host\share\storage.json`解析到其共享根下同一位置；不把母版盘符当成子版盘符。根外Windows位置须明确使用UNC；根相对、盘符相对、越出根的相对路径拒绝。路径映射辅助检查不证明物理SMB连接，本轮未访问正式共享盘。

## 保存及失败

本机设置、共享目录和价格保存沿用完整锁事务、最新哈希/CAS、唯一暂存、写前副本、原子发布和回读。两台母版的旧页面不能覆盖尚未看到的目录修改。读取支持1MiB设置、版本/字段/重复键/路径文本校验；未知版本和坏设置不自动覆盖。目录检查使用独占随机临时文件，仅清理本次文件；不使用固定write_test.txt。价格保存校验整份候选，并禁止覆盖已损坏的现有价格JSON。

目录保存与价格编辑互不写回；价格不可用时可设置有效目录和阅读已确认目录中的账本，正式Excel/截图仍阻断，不以默认价格成交。共享目录不可用时保留显示、阻断列表和输出，不回旧E盘或另造账本。目录切换只改变连接，不移动、合并、删除或覆盖原数据；检查可能创建选定的新输出文件夹，不迁移其内容。提交成功后列表刷新失败显示“已保存”，不报成未保存。

未知设置或PNG发布结果保留请求及恢复诊断，阻断下一次输出，使用“检查上次写入”查询。确认未提交后设置以同一请求重试；确认已提交后核对当前文件再刷新。恢复副本没有自动回滚功能；坏本机设置需核查后显式恢复原件并重启，坏共享/价格文件修复后刷新。不直接拿旧备份价格自动成交。

## 每单价格与图片

新导出的`订单价格快照`表按稳定订单ID、请求ID追加完整价格快照，列为订单ID/请求ID/记录时间/价格版本/规则版本/数值版本/项目名称/销售单价原文/成本单价原文/K系数原文/是否单件。与同一Excel追加事务一起发布；重复点击同一报价不追加重复快照。后续价格更新、新单追加、备注或作废均不删除旧快照。原`价格设定`表首次创建后保留；已有旧表也不重建，不推断旧单完整价格版本。26列明细和原金额规则保持，历史金额不重算。

价格文件变化仍只观察版本；未确认报价不被静默替换，需显式刷新、差异、重算和确认。源文件字节哈希是本地版本标识，不是认证发布者身份。

截图保留母版根目录/子版按天子目录的兼容差异，名称含客户/订单、纳秒和UUID，并限制名称片段长度。PNG包含唯一请求标识，内存验证后通过相同暂存/回读协议发布，仅允许新目标，不覆盖已有图片。同一时间戳连续保存仍产生不同文件。结果不明先查请求，界面不冒充成功。截图诊断使用合成图片，不声称验证真实桌面像素。

## 备份与Rust接续

备份目标可在母版登记，例如用户要求的主机`E:\报价利润计算器备份`，本轮不创建、不设置隐藏/系统属性、不调度备份。当前事务旁的`.777-recovery`继续提供写前恢复副本。独立E盘根Hidden+System/ACL、服务一致性备份及恢复演练仍由P05/P08实施。

P05/P06复用设置版本、路径来源、冻结价格、订单/请求关系与错误语义。Tauri客户端把共享源连接替换为服务连接，输出目录仍为显式设置，数据库仅由主机服务访问；导入新附表须保留订单价格关系。现有共享文件仍可能含成本，隐藏表不构成保密。

## 验证与Windows入口

[辅助证据](P03-03-checks.json)包含完整215项及本任务新增23项，均在临时文件/Tcl变量中执行；不是Windows实测。P03-02已经通过的Windows检查无需重跑。

Windows本机只需在当前分支执行：

```powershell
git pull --ff-only
py -3 tools/p03_storage_check.py --gui-smoke --output reports/p03-03-windows-01.json
```

该入口执行23项合成检查和实际母子Tk隔离联测：母版发布、子版继承/导出/读取、真实新母版窗口恢复设置、首次启动连接、更新价格后保留原订单快照、同时间截图唯一命名、关闭回调清理。配置/账本/图片及本机设置全部在临时目录，不改LOCALAPPDATA或正式共享数据；报告拒绝覆盖已有输出，重复执行换报告名。

正式使用时母版先在Excel记录页选择数据源、保存本机连接、导入旧JSON目录并保存共享目录；子版选择映射到同一目录的UNC源并保存本机连接。已有有效config.json不必重新录入价格。新空目录先显式保存价格和共享目录；目录变更不会迁移旧账本。当前P03-03待本机复查/用户验收，P03-04尚未启动，P03整阶段留now。
