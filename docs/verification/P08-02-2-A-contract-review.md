## 源码与契约核对

- 旧设备票据是单设备、短期限；新可分发包必须另建授权，不改变旧票据语义。
- Host 现有 Actor/admin 判断没有包能力上下文；契约要求 principal_kind + capability + ownership，并覆盖提前返回、下载及重试。
- 首次信任通过仅给部署所有者的专用升级包建立；普通安装包不能包含发行秘密/临时监听私钥，不能凭 IP 自行信任陌生证书。
- 设备主体写入既有 users，新增 device_only 登录模式；避免销售归属丢失及逻辑备份无法解析 owner。节点授权跨库使用意图与回执，不假设跨库事务原子性。
- 包到期、关闭新增、整包撤销、单设备撤销分开定义；同包多设备独立身份，同角色升级保留主体，跨角色不混合待提交请求。
- 保护存储区分桌面用户与后台账户；Hidden/System 属性不被当成访问控制。同步副本对本机管理员的可读性明确记录。
- 新 auth schema 与快照协议需配套升级；旧节点暂停接收不兼容快照，现有 .23/.38 同账本状态没有现场证据。
