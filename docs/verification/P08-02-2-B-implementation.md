固定业务入口为 `https://192.168.4.23:8477`。临时 `8478` 仅允许准备时记录的开发电脑来源、固定临时证书和配对凭据；只暴露绑定路由，最长 30 分钟，重启不延长窗口。确认或过期关闭监听；Windows 提升权限的清理进程只删除本升级的防火墙规则及敏感升级材料。普通服务重启在窗口内保留待绑定状态。

专用升级包与普通安装包分开；发行秘密不在升级包或公共包里。临时私钥属于敏感升级材料，开发状态由 Windows 当前用户 DPAPI 保护；普通包将只携带有范围的登记授权。Windows PowerShell 脚本在专用产物中使用 UTF-8 BOM。

## 复用和兼容边界

- 升级保留 ledger_id、业务用户、TLS 私钥、每日备份路径/计划、原 runner/identity 脚本和任务账户。原任务停机后复用，不登记第二个开机任务。绑定冲突、非主机、目录归属不明或未知数据库保留数据并失败。
- 在替换程序前保留原程序及配置；日记记录候选程序与原账本/证书。替换到程序但配置尚未发布时，允许同候选恢复。迁移后不能只复制回旧 exe；整套回退按 A 兼容契约维护处理。
- 旧设备 v1 登记仍遵守单设备票据语义；新 a2 会话独立命名，不回落为旧维护会话。最后一个可密码登录的维护管理员不能被新设备管理员名额抵消。
- 旧节点迁移新增 `POST /v1/automatic/nodes/adopt`：原节点秘密在 Authorization、新母版登记秘密在 `X-777-Package-Authorization`；核对包/站点/账本/节点摘要后保留原 peer ID。安装器调用及节点本机程序升级属于 C，现场节点不因源码完成而自动升级。
- 新节点许可不授予业务管理员权限；正式母版设备也不能发行旧票据、创建账户或取得维护群集接口。副本继续单向异步复制，不支持故障接管。

## 后续集成入口

`quote-host` 增加 `automatic-prepare`、`automatic-connect`、`automatic-upgrade`、`automatic-revoke` 原生命令，供后续开发界面/安装部署调用。准备和绑定状态在开发侧持久化，正常封包不需要业务登录。它们是内部集成接口，不要求普通用户查找目录、手工输入这些命令或复制登记文件。

此轮没有制作最终 Windows 升级包或普通母／子安装包，也没有更改日常封包界面。E 接选择式界面与开发侧准备；C 接母版部署、原节点采用/续做和服务运行身份；D 接设备候选、保护存储、静默重试及草稿保持；F/G 接剩余备份命名和跨流程日志。

证书轮换、发行凭据更换及人为丢失设备密钥的完整维护界面仍按 A 约束留作维护集成；当前普通正式端不开放这些入口。断线绝不创建空账本或提升副本。
