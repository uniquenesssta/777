## 保留日志的整合

Rust 拆分 `quote-diagnostics/{session,storage,metadata}`；Python 拆分 `operational_logs/`；PowerShell 复用 `host-log.ps1` 与独立提权辅助文件。每次独立运行新建目录，同根目录的相关子进程共享该次文件；跨根目录用 `execution_id` 关联。维护 HTTP 请求附带经过长度/字符核对的 `X-777-Execution-Id`，只做关联，不参与鉴权；不记录原始头、URL 参数或业务正文。正式端不发送随机追踪编号。

单文件上限 4 MiB，最多当前文件加两份轮转（约 12 MiB/运行目录）；保留一个 runtime.lock 处理跨进程写入和轮转。同内容事件一分钟内合并，后续事件或正常退出写 suppressed 数；日志写失败不影响业务操作。元信息包括阶段、错误码、包/节点/数据代、OS 错误类型与位置；意外嵌套的密码、秘密、票据、私钥及完整业务正文会被过滤。不会打印完整子进程参数。

专用主机升级包增加有哈希清单覆盖的公共 execution.json；在请求 UAC 前开启本次维护日志，父/提权子进程显式传同次目录和执行编号，失败只记错误码、类型、HResult、脚本文件名/行号。正式安装使用同一辅助逻辑时仍禁用日志，不记录其 UAC 问题。真实 Windows 权限边界尚未执行验证。

## 离线关闭授权补偿

开发端 `p08_automatic/close_queue.py` 持久化待关闭包编号与重试时间；不写明文秘密。取消先保存 cancelling 状态，确认停止原构建后入队；重启恢复未完成取消。改开新任务时，已放弃的失败候选也入队；保留原失败任务用于重试时不关闭它。

队列后台重试 `automatic-close`，有超时和指数退避，不占用日常界面调用。只使用原候选和原发行绑定；原生先拒绝不同 issuer/site/ledger，再发网络请求。原候选文件保留，不新发授权、不删除业务数据。服务端尚无该包时可结束关闭；网络或绑定冲突保留待处理状态。退出开发版会停止队列，待处理记录留到下次启动。
