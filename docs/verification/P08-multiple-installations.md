# P08 取消同一安装包的单机登记限制

2026-10-21（北京时间）。用户明确要求取消同一安装包只能登记一台电脑的限制。

## 行为

- 母版、子版的同一有效安装包均可登记不同电脑，每台仍有独立设备身份。原设备不自动撤销。
- Host 不再按 manifest 的 max_devices / max_nodes 对单包已使用台数限额；覆盖普通登记、旧设备迁移、设备换包、母版节点登记及节点换包。
- 保留包签名、口令、角色、权限、站点身份、到期/关闭/撤销检查。子版不会因此取得价格发布或节点权限。
- v1 manifest 字段保留兼容，已签名旧包及已登记数据不重写；新封包按服务总容量填入 4096 个设备、母版 128 个节点、子版 0 个节点。总容量保护仍独立执行，更新已有设备身份不新增总名额。
- 服务总容量判断单独放在 automatic/capacity.rs；协议回归按职责放在 repeat_installation.rs。

## 部署影响

要让已生成的单机旧包也可复用，需要更新 4.23 上正在运行的 Host；不需要因此重封现有桌面包。保留原业务数据、服务配置、证书、账本和登记身份。只拉开发仓库代码不会自动替换 4.23 的运行程序。

新生成的包携带较高配额，可供仍使用旧配额判断逻辑的兼容 Host 使用，但旧包里的签名配额不会靠客户端刷新改变。

- `cargo test --locked -p quote-host --test automatic_installation`：27 项全部通过。覆盖旧 max_devices=1 的两种角色在第二台电脑登记、母版实际发布和读取价格、子版发布拒绝、旧包内容不变、签名篡改拒绝、同身份重试、旧设备迁移及覆盖更新、节点复用、撤销/错误凭据拒绝和 Host 升级保留数据。
- `cargo test --locked -p quote-host --lib automatic::capacity`：1 项通过，验证服务总容量边界。
- `cargo clippy --locked -p quote-host --lib --test automatic_installation -- -D warnings`、`cargo fmt --all --check`、`git diff --check`：通过。
