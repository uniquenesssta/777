# 利润切图布局与价格日期序号（2026-10-20）

## 当前行为

用户反馈柱状/折线切换稳定，而饼图/K线会带动汇总区域位移。代码中前两种共用趋势容器，饼图的图例与K线说明/明细产生不同内容高度。现在四图共用独立的自适应显示区域；额外内容在内部滚动，保留K线说明、数据明细和饼图图例，页面汇总区域不随图表内容撑缩。小窗口仍可滚动访问业务控件，大窗口图表随可用高度伸展。辅助环境修前没有复现全部现场位移，因此不宣称已确认 Windows 的唯一原因；修后检查实际汇总卡片及图表外框的位置、宽高一致。

报价标题操作行改为“价格版本 261020-1”在左、“一键清除”在右。通过专用组件和样式承载，移除版本标签原 50% 宽度限制，避免截断日期序号；两个按钮等高，窄窗口允许整行换行。价格刷新与清除的真实功能、待处理请求保护保留。

用户中途明确改为日期加序号，当前实现以该纠正为准：

- `published_at` 取当前价格版本的持久化发布时间，按北京时间显示六位日期。
- `publication_sequence` 依据同一北京时间日期内已成功发布的请求及账本提交序号计算；同秒发布也按真实提交次序计数，不依靠随机版本 ID 排序。首条为 1，次日重新从 1 开始。
- 刷新、重启和读取备份不会单独增加次数；已有当天发布记录计入总次数。后台版本 ID 不变，日期标签不替代核价、并发或历史版本判断。
- 在线目录和离线授权使用同一公开目录投影，新增元数据随离线价格目录保存。序号按既有离线规范传输为十进制字符串，不引入禁止的 JSON 数值；费用字段仍从公开摘要中排除。
- 旧 Host 或旧离线缓存缺少可验证元数据时显示“刷新价格”，不会填入今天日期或猜测序号。正式 Host 需升级；已缓存的旧离线价格在后续有效准备/续期后取得元数据。
