# P08 设置区移除与安装资源隐藏

2026-10-21（北京时间）。按最新明确纠正，移除整个“业务数据保存位置”区域，而非只移除说明：标题、路径输入、选择目录、保存按钮、状态、说明均不再渲染。删除专用 UI 组件和失效样式。保留下面的导出文件保存位置、业务备份及其真实流程。旧本机偏好与原生兼容接口保留，不更改业务数据。

将 NSIS 安装生命周期生成逻辑从封包编排文件拆到 `desktop/tools/installer-hooks.mjs`。母版资源复制完成后、调用后台部署脚本前，为 `$INSTDIR\host` 读取并保留现有属性，增加 Hidden / System（0x6），Directory 保持；读取/设置失败使安装失败，不伪报已隐藏。无需等待服务联网或后台部署成功。只操作该目录本身，不隐藏安装根目录或导出文件，不递归改文件。子版不携带 host 资源，因此不额外创建目录。

验证：TypeScript 和两个 JS 模块的语法静态检查、diff 检查通过；两项浏览器测试通过，覆盖母版整个区域消失、刷新后仍消失、旧目录接口不再请求、导出设置保留及子版设置。遵守约束，未执行母子封包、封包准备检查或 Windows 安装实测；隐藏属性需 Windows 安装后实际确认。没有构建新安装包，也没有更新 Host 程序或业务存储。
