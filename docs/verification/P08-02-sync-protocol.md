采用单一固定主机处理全部业务写入，其他主机加入其业务账本并持续接收完整一致代。默认主机本地提交即返回，后台异步复制；跟随节点业务入口转发给主机，不直接写本地副本。断连时返回可重试失败，保留相同请求ID；不自动升主，不把两个独立账本轮流接单称为同步。自动故障接管尚不在本轮完成结论内。

加入时使用原主机签发的每设备一次性加入文件（公开HTTPS连接、集群/账本ID、短期票据）。新节点在本机产生独立TLS身份和设备随机凭据；初始同步核对同一账本后才注册运行。重试绑定同一节点ID和凭据，票据不能登记第二个节点；不复制源主机TLS私钥或程序，不合并已有独立订单账本。凭据留目标机受保护位置，Windows用当前账户DPAPI加密；日志不写票据、请求正文或同步数据。

复制覆盖订单/客户/历史版本/价格/请求回执、账号权限和设备撤销、输出任务与已完成输出文件。每日备份不作为同步通道。主机持业务互斥锁使用SQLite在线备份生成跨库一致快照，传输仅含白名单数据库和合法输出文件。清单含集群ID、账本ID、单调递增代号及逐文件SHA256；文件分块获取并校验，已存在相同哈希文件复用，断点文件在重启后继续；复用未变化文件，变化数据库以完整一致文件传输，不逐条刷日志。

从机先在私有暂存代下载所有文件，核对数据库结构、跨库用户/订单/输出绑定和文件哈希，再原子发布当前代指针；崩溃或坏块保留上个完整代，拒绝退回旧代和相同代不同内容。从机不会启动本地输出写进程或每日备份调度，不从可能落后的副本授权业务；所有业务校验仍由主机完成。

部署入口区分“建立主机”和“加入现有数据”，显示加入、追赶、已同步、断连、撤销等真实状态。现有4.23在明确启用同步时按同一账户正常停止、升级后台资源并保留账本/证书，再正常启动；不覆盖现有业务数据。UI范围是后台包控制台和系统文件选择器，未更改业务应用画布。

验证需覆盖两真实Rust TLS进程、加入重试/票据重放、同账本与设备身份、订单编辑与输出/撤销同步、断连恢复、坏块/中断发布、主机停止期间从机不写入、重启后续传和日志脱敏。Windows母子版构建准备仍取消，不下载远端测试包，不在真实订单上做故障试验。

## 协议与资源边界

原生操作拆为cluster配置、成员授权、快照、传输、复制循环和控制命令；部署拆为文件/清单、主机升级、加入模块。TLS精确指纹校验和Windows DPAPI由quote-security共享，桌面入口维持原合同。

数据分块256KiB。白名单单文件最多256MiB、总量8GiB、最多20000文件和128个节点。成员凭据、票据在主机只保存SHA256；从机凭据和重试票据使用当前Windows账户DPAPI。公开connection.json不含加入票据。加入只接受新目录，初始化在临时兄弟目录完成后一次重命名，使选定目录从出现起即可重试。断电前的未发布引导目录可能留作人工检查，不影响重试，不会含现有业务订单。

主机保留当前和上一完整代，以及正在传输且租约未过期的代。每次块请求续期120秒；不断有新订单也不会立即清掉从机正在下载的旧代。离线过久后租约过期，再取最新清单，按哈希复用已完成内容。复制缓存只保留当前/输入清单需要的哈希，清理协议命名的孤立暂存；日志只记状态转换和发布摘要。副本发布和服务重启都检查全部文件与数据库一致性；同代轮询依赖已验证的不可变代，不每2秒重新全盘读取。

服务正常停止释放独占账本锁后才允许升级。已有受保护后台文件由显式select-host --upgrade-resources进行管理员认证替换，随后核对账本ID及证书不变，更新原部署资源哈希。若原生选择已完整成功、但更新部署清单前中断，重试只允许当前已校验程序包的精确新主机哈希，并仍由原生独占锁、密码认证和账本/证书检查兜底；未关联的程序文件或其他Windows账户不能恢复写入。选择命令内部多文件替换的任意断电点不在此次自动恢复证明内，资源摘要冲突会保持停止并要求维护，不跳过校验启动。

原生日志不回显命令结果正文；加入文件由控制台捕获并写入用户指定的新文件。所有HTTP同步轮询/分块不逐次记http.finish。空认证头现在稳定返回401 UNAUTHENTICATED，避免设备认证回退把缺少凭据误报为422 INVALID_TEXT。

## 操作与现场边界

完整操作见deployment/bundle/README.txt的8、9、10、11、12菜单说明。新程序必须使用npm run package:host重新构建，不可拿旧原生文件只重包脚本。加入与运行不要求服务电脑安装开发者版或共享业务目录。脚本不嵌入业务密码；Windows登录密码由本人输入系统框。

本轮实现固定主机＋异步副本；不宣称同步提交、双主写入、自动主备切换、IP漂移或客户端自动换服务。母子版业务UI未改动。4.23原服务和4.38现场尚未执行本轮升级/加入，不能用隔离CI代替真实完成记录。正式使用现有公开连接仍指向其选择的节点，后续故障接管和切换另按P08任务推进。
