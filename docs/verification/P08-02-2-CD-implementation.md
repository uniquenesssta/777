## 实际接入

| 职责 | 代码 | 行为 |
| --- | --- | --- |
| 选择式封包 | `desktop/src/features/packaging/` | 母/子选择、权限依赖、真实任务状态、原任务重试；无连接目标、业务账号、证书或导入表单 |
| 开发数据与发行准备分离 | `DeveloperPage.tsx`、`DeveloperData.tsx`、`tools/p08_automatic/` | 保留兼容来源验证；封包状态只依赖独立发行配置，当前业务连接失效也能进入封包；临时来源不改变固定目标 |
| 两段发行 | `desktop/tools/automatic-release.mjs`、`package.mjs`、Host `automatic/issuance.rs` | 先构建不可变程序，规范清单包含程序及全部资源；再登记包和写入受限封套，最后打安装器；发行者秘密不进入安装包 |
| 母版后台安装 | `deployment/windows/automatic/install*.ps1`、`node-run.ps1` | 核对已有任务和本地归属，复用原主机；其他电脑注册独立副本任务；不再索取加入文件 |
| 原生节点接入 | Host `automatic/installation/` | 先持久化候选，再领许可、加入和同步；旧节点需原秘密；已知暂存区中断可续做，发布到业务根目录前永久标记为副本 |
| 自动桌面身份 | `desktop/src-tauri/src/client/automatic/` | 当前业务用户独立保护身份；同角色升级保留 ID、subject 和未决请求，校验证书/站点/账本/包权限；无旧登录回退 |
| 旧桌面采用 | Host `automatic/legacy_device.rs`、`devices.rs` | 原设备秘密和新包授权共同证明，保留原销售归属，停用旧设备会话，维护管理员及其密码保留 |
| 重试与静默 | 原生 `client/retry.rs`、共享 `quote-security/retry.rs`、后台 runner | 短暂失败指数退避并加抖动，通常上限 5 分钟；授权/身份冲突慢速复核；尊重服务端 delta-seconds Retry-After（上限 24 小时）；不生成新身份绕过拒绝 |

固定业务目标为 `https://192.168.4.23:8477`。只由已绑定的原生发行档案取得目标及 TLS 信任，不从开发工作副本取得，不要求终端共享三个部署目录。包内登记凭据有期限、额度与权限，不能直接用于业务或后台维护登录。

封包失败保留受保护候选和已构建负载；重试沿用原包编号、版本、权限、运行库和输出位置。不可变内容、源码或负载变化时拒绝覆盖原记录，需要新任务。只有登记和最终产物完整性核对均成功才提供“打开产物文件夹”。取消会尝试关闭未交付授权；离线关闭失败仅留待维护日志，持久补偿和完整运行日志归并仍属于 G，不能宣称已全部完成。

## 安装和数据保护边界

新副本默认位于 `%ProgramData%\Quote777\`，包含同级 `Quote777Host`、`Quote777Service`、`Quote777Hidden`。`Quote777Hidden` 是本机普通备份位置；固定 UNC 隐藏备份沿用主机现有配置。只设置三个顶层目录 Hidden + System，Directory 是原有目录类型；不递归处理，不对 UNC 目录改属性。已存在的有效部署沿用其目录和账户。

- 在 4.23 核对部署归属、账本、证书和站点后复用原任务，不重写主机账户、备份、证书或业务数据。只有本机 IP 匹配但找不到可信原部署时拒绝初始化。
- 新副本使用 SYSTEM 的开机任务；节点秘密由该身份生成并保护。桌面设备秘密由实际业务用户首次运行生成，两者不复制 DPAPI 密文。不增加业务密码输入。Windows 需要的 UAC 授权仍保留。
- 原有副本保留任务、原 Windows 账户和其共享盘权限；只在核对归属并正常停止后更新 runner/Host。旧兼容账本 worker 保留。未知目录、不同账本、凭据丢失或归属冲突不自动覆盖。
- 节点下载完整快照并验证实际账本、数据代后才记 ready；主机不可达时任务保留候选并重试。后台独立于业务窗口，卸载界面不删除数据、备份或注销后台任务。
- 母版节点拥有同账本完整复制权限；业务功能复选框限制业务身份，不承诺同步电脑的系统管理员无法读取本机副本。子版不携带 Host 程序和部署脚本。
- 仍为主机落盘、从机异步同步，无故障接管。正式业务只连 4.23；安装副本不会带来离线开单能力。

正式版无账户、登录、退出登录、连接或登记故障提示；首次等待保留空白工作区，失联保留既有授权视图和草稿，未决写入保留原请求并禁止盲目重发。收到撤销时撤下失效业务状态，身份冲突不清除候选或改建匿名身份。
