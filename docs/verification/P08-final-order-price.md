# P08 整单最终成交价

## 已实现行为

- 报价工作台右侧“折扣合计”下增加“最终成交价”，保留上方自动计算的应收合计。核价后填写，空白显示并采用自动金额；可以清空恢复自动金额，支持 0 元，拒绝负数、超过两位小数和金额容量溢出。
- 成交价在全部顺序折扣之后覆盖整单收入，不再次折扣、不改变商品原价、尺寸、成本或商品排列。利润为成交价减成本，利润率同步刷新。未授权财务的界面不获得成本/利润。
- 只改变成交价不要求用户修改尺寸或再次点击核价。提交时自动以新草稿版本执行原生核价，再沿用原有提交检查；改动后又清空、恢复相同金额也会校验，未绕过快照或价格版本检查。
- 草稿在本次软件运行期间记忆成交价，一键清除和订单提交后的重置清空它。重新启动仍按原规则清空工作台。订单再次编辑会读取已保存的成交价。
- 核心 Quote 使用可选 `final_price` 元字符串；缺省/null/空白代表自动金额。保存到既有 `input_json`，不增加数据库列，不更改旧订单默认算法。
- 本机离线正式订单、上传原件、服务端应用、下行订单分块、历史归档和备份恢复保留此字段。编辑上传字段缺省表示不修改，null 表示恢复自动金额。不同成交价并发修改，或成交价与明细并发修改，进入财务冲突；独立客户字段修改可继续合并。
- 订单合计及财务统计使用实际收入；修改记录保留成交价前后值及收入/利润变化。Excel 保留原始商品/折扣明细，并用“成交调价”行解释差额；合计不重复计入差额。报价图片标注“最终成交价”，继续保存本机 JPG。
- 使用已有结算区的底部空位容纳新字段，不改变订单详情布局。现有 Figma 文件 `2ek9bkIz5ldyhjZnnvIuNu` 已同步：母版行 `171:2355`、子版行 `171:2359`；母版结算区 `22:464` 截图检查位置及文字无重叠。

## 更新范围

需要更新 4.23 的 Host，以及开发版/母版/子版桌面应用；已安装的正式端需要重新封包并覆盖安装。旧 Host 不接受这个新增字段。更新应保留现有业务目录、账本和证书；不需要删除数据或重新创建账本。旧订单读取时继续使用自动金额。
