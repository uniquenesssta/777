# 本机签发与自动首次接入（2026-10-20 修订）

此文覆盖旧 trust/issuance 文档中“开发者必须先连接 4.23 完成发行绑定才能封包”的要求。旧接口仅保留兼容；新封包不调用它们。业务入口仍是 `https://192.168.4.23:8477`，E 业务冲突核对继续暂停。

## 信任与操作顺序

1. 开发电脑自动建立持久 Ed25519 签发身份，私钥由当前 Windows 账户 DPAPI 保护。封包只读取本机身份，不向 4.23 请求授权，也不要求已知真实站点或账本编号。
2. 开发者在应用封包选择母版/子版及功能。`777-local-package-v1` 包含签名、公钥、固定首次接入证书、角色/权限/版本/包编号/程序资源摘要，以及仅属于该包的登记秘密。签名覆盖公开连接资料与全部清单；登记秘密的摘要也在签名内。
3. 普通 `Quote777Host.zip` 出包从同一开发身份导出 Host 接入材料。在 4.23 运行普通 `deploy.cmd` 更新已有后台，保留业务账本、8477 证书、账户、任务所有者和备份配置。此维护可在桌面封包之前或之后完成，不是封包前置认证。其他主机不安装主站信任。
4. 正式端首次联网向固定证书的 `192.168.4.23:8479` 注册。该入口仅处理签名包注册，不处理订单、发行者会话或普通管理请求。服务器比对已部署公钥及完整公开配置，验签、权限上限、有效期、额度和撤销状态，幂等创建包授权，再返回现有真实站点、账本和原 8477 证书。
5. 客户端核对返回的角色/权限/版本/资源摘要等全部字段与原签名清单一致，再保存受保护绑定，沿用原设备/节点登记、会话和权限裁剪流程。母版身份不能靠修改前端字段获得；子版不能获得节点权限。

开发签发私钥不会进入 Host 包或桌面安装包。Host 包只含签发公钥及**首次接入服务 TLS 私钥**，仅供后台维护者部署；桌面包只有该证书的公开部分。不要将 Host 部署包混入对外桌面交付。已有 8477 私钥无需导出、共享或重新签发。首次接入证书有效期 10 年；到期或更换开发身份需另行明确维护迁移，不静默替换受信身份。

## 生命周期

- 本机候选在生成后、输出前持久化；同一失败任务重试保持包编号、秘密、签名与清单。内容变化须新任务。
- 每个新包登记期限 365 天、桌面名额 1；母版另有 1 个同步节点名额。设备和节点各自独立凭据。原身份重试/同角色升级沿用既有规则，不删除身份以绕过额度。
- 新包在首次安装接入时才登记到主机；取消本机任务不伪称已经远程撤销。旧在线发行任务仍使用原关闭补偿队列，新任务候选与旧队列分目录保存。需要撤销已登记包时仍由 Host 所有者维护命令处理。
- `package_id` 是首次注册幂等键。不同内容撞号拒绝；关闭、撤销或禁用签发者后重复提交不会复活授权。
- 初次接入成功后，桌面和节点分别保存受保护绑定缓存。重新打开无需重复注册；缓存按原签名包指纹匹配，不能拿另一个包的响应混用。设备、未决请求和已有账本身份校验继续有效。
- 初次未联网的母版安装，后台任务先按真实签发者标识命名，账本/站点字段留空；真实接入与完整副本检查成功后才写入账本/站点。不得生成假账本或报告同步完成。
- 本机识别出的既有主服务直接保留，不因安装母版重写主机运行身份、证书或备份；真正桌面授权仍由服务器核验。
- 首次接入限请求体 64 KiB、4 个并发连接/请求、10 秒头部/正文超时、每分钟限流。客户端固定 HTTPS、禁止重定向/代理、限制返回大小并核对证书及签名，不使用 IP 自信任、跳过证书检查或通用管理员密码。
- 正式端无登录/退出、无接入/离线/技术错误提示、无诊断日志。原生后台按既有退避和重连机制恢复。离线正式入账条件继续遵循 P08-02-3 D，不因本次封包改动另建账本。

## 兼容与边界

旧 `777-automatic-package-v1`、设备、节点、业务 TLS 和授权库 schema 2 保留。新协议通过专用受保护信任文件和原包授权表接入，不增加与旧库不兼容的授权表。原始备份共享仍只提供备份能力。

源码/协议/界面检查与真实 Windows 安装、UAC、SYSTEM 任务、DPAPI 跨账户、现场网络验证分别记录；不因辅助环境通过宣称现场完成。不运行用户取消的最终母子包构建及构建准备专项，提交后不轮询 CI。
