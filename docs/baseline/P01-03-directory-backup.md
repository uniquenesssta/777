## 2. 可见目录设置

统一设置入口为“设置 → 存储与备份”。所有可用目录显示当前完整路径、用途、来源、保存结果；管理员可选择文件夹和应用。无需编辑Python顶部常量或重新编译Rust。中文、空格、本机路径和UNC均须覆盖。

| 项目 | Python过渡期P03-03 | 服务/Tauri阶段P05/P07 |
| --- | --- | --- |
| 本机设置位置 | 建议使用系统用户应用数据目录，例如%LOCALAPPDATA%/QuoteProfitCalculator/settings.json，独立于业务/价格目录 | 复用同一设置模型或提供版本适配；路径由系统目录解析，安装盘符不决定存储位置 |
| 业务数据源 | 管理端可选择本地根或UNC根；销售端选择共享源，用于当前兼容读写 | 客户端设置服务地址/连接状态；账本本地目录仅服务主机管理员可设置，销售端不访问数据库或含成本共享文件 |
| 价格来源 | 独立字段明确显示，避免把价格目录当导出目录；销售端只读设置来源 | 由服务发布价格版本，销售投影不含成本；历史订单保持原版本 |
| Excel导出目录 | 母子版显示并使用已保存的目录，重启保持；读与写使用同一已应用值 | 仅报表输出，不决定权威账本；可为本地或共享路径 |
| 图片目录 | 显示并选择；保留两版已有的按天命名差异作为兼容选项 | 受控附件根及唯一文件名，目录变更不改历史附件归属 |
| 备份目录 | 管理端登记主机备份目标，准备独立恢复副本路径；过渡写前恢复副本遵循P03锁协议 | 主机管理员管理计划与恢复，销售端没有备份/恢复接口或路径访问权 |

首次启动未配置时引导选择；可展示系统应用数据目录下的业务目录作为建议，用户应用后才生效。旧E盘/UNC地址可作为明确标为“旧版目录”的导入选项，显示后由用户选择；正常启动不把旧路径用作静默fallback。

设置保存采用版本化、校验、临时保存与安全发布；路径可读/可写检查使用唯一临时文件并清理。失败保留上次有效设置并显示具体状态，不伪装“已保存”，不切回固定E盘成交。价格不可用按business-v1保留草稿并阻断正式提交。启动恢复设置须早于价格加载、账本列表与截图路径初始化。

目录变更默认只切换配置，不自动移动、合并、覆盖旧数据。界面显示旧/新位置及用途；需要迁移时走独立、可审阅的副本迁移流程。服务主机账本路径变更属于管理员维护操作：停止新写、验证备份、核对schema/数据、原子切换并重启验证，客户端不能通过改导出目录另建权威账本。

## 3. E盘根目录备份

用户已确定位置类别及隐藏要求；具体目录名建议为服务主机本地`E:\报价利润计算器备份`，在管理员设置页显式显示，可调整。E盘仅为此次备份目标，不成为业务/报表/价格/图片的固定根。盘符不存在或无写权限时显示备份失败，由管理员选择有效位置，不自动改到旧业务目录。

新建应用专属备份目录后，仅对该目录设置Hidden+System属性并读取验证，用于资源管理器“隐藏受保护的操作系统文件”显示规则；不修改全局资源管理器选项。显示效果在目标Windows实测，不宣称任何情况下绝对不可见。Hidden/System是文件属性；实际访问限制使用文件系统ACL和business-v1管理员/销售权限。备份可包含成本账本，仅服务身份与授权管理员可读写，销售共享权限不得继承到该目录。

| 项目 | 具体建议（实施时可在管理员设置页调整） |
| --- | --- |
| 责任 | 服务主机单一备份任务；管理员负责查看失败状态和恢复，避免两台母版重复调度 |
| 频率 | 有变更时每30分钟一次；每日02:00生成日备份；schema升级/导入/账本位置迁移前生成维护备份 |
| 留存 | 最近48份滚动备份、30份日备份；维护备份及至少一份已验证可恢复备份不因滚动策略自动删除 |
| 内容 | 一致性账本快照、价格/规则/schema版本、必要设置与附件清单/所需附件；凭证采用单独恢复流程，不写入公开报告 |
| 命名与清单 | 时间＋唯一backup_id，记录文件哈希、版本、完成状态和恢复验证结果；临时/失败产物不标为成功备份 |
| 发布 | 在临时目录完成快照与校验后发布唯一备份包；仅清理清单内由本应用创建的过期备份 |
| 失败 | 保留最近成功副本，显示最后成功时间与本次原因；备份失败不撤销已提交订单，维护性迁移先满足备份门槛 |
| 恢复 | 在独立目录打开并核对完整性、schema、订单/明细数量及收入/成本/利润、附件；正式恢复停写并处理恢复点之后的增量 |

SQLite在线账本采用其一致性备份接口或经验证的等价方式；运行中不把单独复制主db文件当完成快照。P03的共享Excel写前副本在完整锁事务内生成、记录哈希，不能把P05数据库备份协议提前写成Python已实现。E盘本地副本登记为本机恢复点，跨设备灾备当前未实施。
