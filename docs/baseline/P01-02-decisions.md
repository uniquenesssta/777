## 4. 权限验收准备

完整候选矩阵已覆盖管理员、销售、未认证、直接调用API/IPC，以及备注追加/历史保留、作废/恢复、查询范围、导出字段。P05/P07须在服务实现后执行下列场景，本任务不宣称已有接口或已通过。

| 场景 | 候选预期 |
| --- | --- |
| 未认证请求报价/订单/价格/附件/导出 | 认证失败，不返回受保护业务数据 |
| 销售甲提交时伪造actor=乙或role=admin | 服务忽略/拒绝自报身份，甲只能作为甲操作 |
| 销售甲查询全部或按ID访问乙订单、附件、导出任务 | 列表只含甲；乙资源按未找到处理；导出/任务同样检查归属 |
| 销售甲给本人追加备注、给乙追加备注 | 本人允许；乙拒绝；旧备注不可覆盖/删除 |
| 销售甲对本人/他人订单作废或恢复 | 均拒绝；管理员带原因和正确revision才允许 |
| 销售绕过隐藏控件直接调用价格发布/财务接口 | 拒绝；不能从嵌套价格快照、Excel、图片或本地缓存取到成本/利润 |
| 旧revision更新、重复request_id、同键不同请求体 | 冲突或幂等结果；不能因已授权而绕过一致性检查 |

认证方法、账号来源、主机拓扑和真实所有者映射留在P01-03/P05；不以客户ID充当账号，不凭旧表时间或文件名伪造actor。迁移历史中无actor的数据须待核对归属；销售查询不默认把未知归属订单算作本人。
