## 3. 只读采集入口

[tools/collect_p01_samples.py](../../tools/collect_p01_samples.py)仅读取明确选择的文件，不导入或启动两份业务应用，不遍历共享目录，不自动猜日报日期，不执行公式/宏/外链，不访问未选中的生产路径。没有新增依赖，复用openpyxl。

每次使用一个新的`reports`子目录；既有目录拒绝覆盖，符号链接/junction输出拒绝，采集前后哈希不一致时阻断公开快照。原件不写；副本设置只读。单文件20MiB、ZIP展开总量64MiB、每表1000行/64列为采集容量保护，超出明确报错或标采样截断，不是生产金额/数据量限制。

在能读取母子两个路径的电脑上，例如：

```powershell
git pull
py -3 tools/collect_p01_samples.py `
  --manager-config 'E:\14T共享盘\葛宁\PyInstaller\config.json' `
  --sales-config '\\192.168.4.38\14T共享盘\葛宁\PyInstaller\config.json' `
  --excel '实际当前日报完整路径.xlsx' `
  --excel '实际旧版账本完整路径.xlsx' `
  --output reports/p01-03-run-01
```

两个Excel参数必须替换成实际文件；如果没有其中一种，省略该参数并说明没有。若当前电脑只能读取子版配置，可只用`--sales-config`；母版端另采一次`--manager-config`。额外配置可用重复`--config`参数。失败不改原件；修正路径后使用新的输出目录，如`reports/p01-03-run-02`。

| 输出目录 | 内容 | 用途 |
| --- | --- | --- |
| `private` | 原始只读副本、真实来源路径和时间/哈希 | 仅保存在用户机器；不上传、不提交Git |
| `public` | manifest及匿名JSON表格快照 | 人工复核脱敏后回传；包含格式、字段位置、原件SHA-256和已保留数值 |

客户/订单/微信/商品名称用同批次稳定编号替换；数字型客户标识同样脱敏；未知字段值、自由文本及公式文本不公开。为复核金额/历史差异，public仍保留价格、成本、金额、数量与记录时间；它是结构化脱敏材料，不能称为完全匿名的公开数据。回传前查看public，确认这些业务数值适合提供给本次审计。`reports/`已被Git忽略；工具不会自动上传或推送采集数据。

回传**public目录中的JSON文件**即可，不提供private。原件哈希和源行位置用于关联本地只读副本，真实账本不进入仓库。本仓库保存工具、合成检查及回传证据摘要；不保存实际商品/价格记录、真实配置/账本原件或客户记录。
