## 1. 用户目标与范围

**用户只在封包时选择母版或子版及功能权限，拿到安装包后正常安装即可使用。** 所有正式端默认连接主服务器 `192.168.4.23:8477`；无需寻找、复制或导入连接文件，无需填写地址、证书、业务账号密码、设备登记文件或主机加入文件。

母版包含原有一键后台部署能力，安装过程中自动完成后台配置和同账本加入。子版只安装业务客户端。4.23 是固定业务主机；38 及其他母版电脑的后台是同步节点，不因安装新母版产生另一份独立业务账本。

本任务覆盖 P08-02-1 的日常手工连接、独立目标填写、安装时选择登记文件等操作要求。既有手工工具可保留为开发维护能力，但不能成为正常封包、安装的前置步骤；旧文档保留历史，不据此要求用户继续找文件。

## 2. 预期使用流程

| 使用场景 | 用户操作 | 软件自动完成 |
| --- | --- | --- |
| 开发电脑封包母版 | 选择母版、勾选功能权限、点击封包 | 使用固定站点配置和受保护的发行授权，生成含后台部署能力的安装包 |
| 开发电脑封包子版 | 选择子版、勾选允许的功能、点击封包 | 生成自动连接 4.23 的客户端安装包，不携带主机部署能力 |
| 4.23 本机安装母版 | 正常安装；接受必要的 Windows 系统授权 | 识别并复用已有主服务、账本、证书和运行配置；需要时执行兼容升级，不重复初始化 |
| 38 或其他电脑安装母版 | 正常安装；接受必要的 Windows 系统授权 | 部署本机后台、登记独立节点、加入 4.23 的同一账本、下载初始完整数据并配置开机启动 |
| 其他电脑安装子版 | 正常安装 | 自动登记独立设备身份，按包内授权连接 4.23 |
| 日常使用及重启 | 打开对应软件 | 自动恢复身份、连接和后台同步；关闭业务窗口不停止后台 |

版本号、产物目录、运行库选项沿用默认值或既有按钮选择，不新增手填连接配置步骤。封包使用固定正式站点，不随开发者临时读取的本地、离线或其他 Host 数据源改变。

Windows UAC 或系统要求的当前 Windows 账户凭据与业务账号不同；不承诺绕过操作系统授权。安装业务流程不得额外弹出后台账号密码或文件选择器。

## 4. 必须保持的约束

1. 4.23 作为固定主服务器，正式端不展示或编辑其地址、证书、主从角色及内部配置。开发维护可查看真实信息。
2. 所有正式端保留“无账户菜单、无登录、无退出登录、无连接/登记提示”的要求。只显示获授权的业务功能及必要业务操作，不新增全局提醒条。
3. 连不上主机时静默重试、限制无法完成的提交并保留草稿；不得自动初始化空账本、宣称保存成功或切到独立账本。未知提交保留原请求 ID，核查后再处理。
4. 不要求共享 `Quote777Host`、`Quote777Service`、`Quote777Hidden`。业务读写及节点同步通过服务协议；仅既有隐藏备份目标本身是 UNC 共享路径。
5. 新部署的三个 Quote777 目录同级，Service 和 Hidden 跟随 Host 的位置自动创建，不再逐个选目录。仅这三个本机顶层目录设置 Hidden + System，Directory 是目录固有属性；不递归修改文件和其他目录，不改网络共享属性。
6. 备份语义不以名字判断：本机 `Quote777Hidden` 是普通备份位置；隐藏备份固定为 `\\192.168.4.23\共享\backup`。现有服务的有效目录及运行身份保留；发现不兼容时保留原数据并记录，不强迁移。
7. 主机负责业务写入、输出任务和每日备份；同步节点不重复生成主机输出或每日备份。客户端仍向 4.23 提交业务，本机副本不开放为第二个写入主机。
8. 4.23 离线时不把 38 或其他副本自动升主；此前“23 → 38”自动切换及安全接管需求保留为后续独立范围。
9. 正式母版“业务数据保存位置”继续按既有约定只保存偏好、不应用到 Host，不能影响安装器选择已有服务目录。
10. 代码按功能职责拆分；涉及 UI 先在既有 Figma 文件中设计，再接入源码。

## 5. 实施任务

### A. 固定站点与发行授权协议

- [ ] 定义固定主机、站点/账本身份、证书信任、发行包编号、母/子角色及权限清单的协议和版本兼容规则。
- [ ] 明确首次信任如何从 4.23 既有部署及授权建立，并整合到一次性主机升级/发行准备流程；不能仅凭 IP 相同接受陌生证书，也不能关闭 TLS 校验。
- [ ] 封包电脑保存受保护的发行授权，日常封包无需重复输入业务账号密码、寻找证书或复制配置文件。不得把“让用户再手工导入一次”写成正常工作流的替代方案。
- [ ] 设计可分发安装包的授权有效期、撤销和升级策略；同一个合法安装包可安装多台，各设备生成独立身份及凭据，重复安装识别原身份。
- [ ] Host 绑定并校验发行包的站点、角色与功能上限；子版不能通过改参数获得母版身份、财务或节点加入权限。同步后台身份和桌面操作身份分别管理。
- [ ] 保持销售订单归属规则，明确自动登记后的销售主体映射；不同设备不得意外共用管理员身份或混合销售归属。
- [ ] 不在仓库、公共安装包、普通配置和日志中存放管理员密码、站点私钥或可无限制管理后台的通用凭据。自动登记不等于开放匿名管理员接入。

完成标准：信任来源与授权生命周期明确；能解释旧主机为什么需要升级，以及自动接入如何在不要求用户填表的情况下成立。

### B. 4.23 主机升级与已有部署复用

- [ ] 检查当前服务/设备/同步协议，提供保留账本、身份、证书、备份配置和运行账户的兼容升级路径。
- [ ] 新增自动桌面登记和自动节点加入所需的受控接口，记录每次发行、登记、撤销与节点加入结果。
- [ ] 安装位置在 4.23 时，依据已有部署归属、服务身份和账本共同确认“复用主机”，不能只凭本机 IP 判断并覆盖目录。
- [ ] 新流程重复执行保持幂等；已运行服务、现有开机任务和同账本副本可识别复用，避免重复任务、端口冲突和重复节点。
- [ ] 已有独立账本或无法核对归属时保留文件，不自动合并、重置或拿测试账本覆盖。

完成标准：兼容升级和中断重试不改变业务账本身份；没有“连接失败后创建新主机”的分支。4.23 的实际升级由现场执行结果单独登记，不能以代码完成代替。

### C. 母版安装集成后台部署

- [ ] 把现有独立 Host 部署模块按职责复用到母版安装流程，包含后台程序、部署、身份、开机启动、同步及日志。
- [ ] 自动创建同级三个目录，设置顶层属性；选择后台运行方式时兼顾开机自启、权限和已配置 UNC 备份访问，不为省操作改坏现有服务账户。
- [ ] 在非主机电脑生成本机节点身份，在线领取受限加入授权并完成同账本初始化，不再选择 `.777join`。
- [ ] 持久化部署进度；网络中断、取消或重启后从可核对状态继续，避免产生半套可写账本。
- [ ] 安装过程中主机离线时记录待接入并后台重试；允许软件静默等待，但不得记录“登记成功/同步完成”。
- [ ] 后台在业务窗口退出后继续运行，系统重启后自动恢复；重复安装和升级保持节点身份及数据。
- [ ] 卸载业务界面不得默认删除业务数据、备份或停止仍承担同步的已有后台；明确后台资源归属与清理边界。

完成标准：母版安装不需要另开 Host 菜单、输命令或选加入文件；同账本关系与同步结果可由维护日志核对。

### D. 子版安装与两版自动连接

- [ ] 子版仅携带客户端所需资源，不安装同步服务和主机管理工具。
- [ ] 安装或首次启动自动登记设备并保存在本机保护存储中；重启复用，安装升级不重置身份与未决请求。
- [ ] 默认连接 4.23，连接参数由包内站点配置提供，不再依赖安装目录外的原始 `connection.json`。
- [ ] 母版和子版均不出现登录/退出登录、后台地址、证书、票据、登记和故障弹窗；内部失败只写有限日志并自动重试。
- [ ] 不同角色或权限的包升级、身份被撤销、服务身份变化时仍守住授权边界，不能降级为共享账号或无鉴权访问。

完成标准：分发安装包即可进入自动接入流程，不需要每台另发一份登记 JSON；无授权或尚未接通时不显示越权内容、不假报可用。

## 6. 针对性检查与完成条件

| 场景 | 必须验证的结果 |
| --- | --- |
| 同一包安装多台 | 独立设备身份、相同目标账本、权限匹配，无一次性票据争用 |
| 母版在主机安装/升级 | 复用现有主服务，不重建账本、证书或删除旧数据 |
| 母版在同步电脑安装 | 独立节点加入同一账本，无第二写入主机，无重复输出/备份任务 |
| 子版安装 | 没有本机 Host；不允许节点加入、成本/财务或管理员旁路 |
| 重试、重启与重复安装 | 身份和部署进度保持，后台能恢复，原提交不重复落单 |
| 主机断线/证书变化 | 正式端无技术提示；数据和草稿保持，不信任未知服务、不自动升主 |
| 改包、角色冲突、撤销 | 原生和 Host 拒绝越权，日志可诊断，无共享管理员回退 |
| 每日备份 | 可恢复文件与可阅读 Excel 一致，双位置状态真实，正式端不泄漏隐藏位置 |
| 界面 | Figma 与实现对应；正常封包及安装无需连接文件、业务账号密码或逐项路径填写 |

检查范围遵守用户既有要求：**不重新安排 Windows 母版/子版构建准备验收、安装包构建验证、远端测试包下载或 Linux/macOS 产品验收；最终封包在用户本地完成。** 实现阶段采用有针对性的权限、协议、部署状态和界面检查，不用模拟结果冒充真实 Windows 安装/4.23/4.38 现场通过。用户后续实际安装回传作为独立现场证据，不预先勾选、不以本任务书要求其重跑已取消的验证。

## 7. 执行顺序与交付
