## 共享协议验收要求

锁必须覆盖完整“读取最新版本→校验revision→修改→安全发布”，所有客户端使用同一锁资源；仅mtime检查仍有检查到保存之间的竞态，仅atomic replace仍会丢更新。现有未升级客户端与外部Excel不遵守应用锁，因此要明确兼容使用模式、检测到外部修改时拒写；不能承诺任意外部编辑并发安全。

用真实Windows共享盘、至少两个写客户端、Excel占用、只读目录、连接中断进行验证；本地合成交错测试仅作补充。底层存储不支持所需保证时，不宣布通过；暂停多人写入并转入经批准的统一写入口方案，调整计划后才能继续。

退出门槛：所有写路径有安全性和恢复证据；未知格式零破坏；身份碰撞和重复提交关闭；旧写端退出或隔离。仍未实现成本保密需如实保留A05开放状态，不将本阶段等同整个产品上线批准。

## P01-03确认后的目录要求

P03-03按[目录/备份定义](../baseline/P01-03-directory-backup.md)实施母子版可见数据/价格来源、Excel/图片位置及管理端备份目标，本机设置独立于价格JSON。启动先恢复保存的设置，去掉现有E盘/UNC常量的隐性fallback；旧地址仅作显式导入选项。设置页显示完整路径/用途/保存结果，覆盖非E盘、中文路径、UNC、保存重启和旧固定目录不可用的情形；路径失败保留有效设置，切目录不自动移动/合并/覆盖数据。

母版1～2台、销售数量未定、共享目录同源已由用户登记。真实锁协议测试记录写端数量，不作无限并发保证。P03负责可见设置和完整锁事务内的写前恢复副本；主机自动备份、Hidden+System/ACL、一致性数据库快照和独立恢复由P05/P08实施。
