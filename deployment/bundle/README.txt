777 通用 Windows 后台部署包

本包可在任何准备作为服务主机的 Windows 电脑使用，不限定192.168.4.23、不要求D盘。
在哪台电脑执行部署，后台就安装在那台电脑；本包不是远程推送安装工具。
开发电脑运行 npm run package:host 出包。本轮新增同步后台，必须重新构建；旧程序不能使用 --skip-build 代替升级。
服务电脑无需 Git、Node、Python、Rust SDK、Tauri 或开发者版，只使用 Windows 自带 PowerShell 5.1。

解压到任意可写的本地文件夹，双击：
  setup.cmd   选择本机服务地址和目录，准备后台、注册自启、启动并检查HTTPS。
  manage.cmd  中文菜单：部署、启动/停止、日志、目录、同步主机、加入文件、加入数据、同步状态、撤销节点。
  check.cmd   查看本机状态或按公开 connection.json 检查另一台电脑的后台。
  collect.cmd 只读采集当前电脑信息。
无需输入 PowerShell 长命令。需要提权时保持当前同一 Windows 账户。

首次使用会识别本机IPv4；多个网卡时选择其中一个。数据、普通备份和隐藏备份目录可以选择：
  回车接受本机默认位置（Windows ProgramData下的独立目录）；
  输入1打开Windows文件夹选择器；也可以直接粘贴完整路径，包括共享路径。
数据根必须位于本机固定磁盘；备份仍支持用户选择的共享/映射/隐藏位置，且与业务根分开。
服务根与程序包分开，程序包本身可放在任意文件夹，不要求固定盘符。

本机选择保存在程序包的 host-local.json，不含密码；复制到其他电脑时自动忽略原电脑的选择。
已有后台：选择现有服务根即可沿用原地址、目录、密码和账本，不重建、不重置、不停止运行中的后台。
兼容已有4.23现场：若D:\Quote777Service存在，会识别并沿用；这个目录仅用于发现旧现场，不是新电脑的固定位置。
全新后台：首次准备通过隐藏输入设置业务管理员密码（12～128字符），密码不写入包或日志。
首次安装自启：系统凭证框自动填写Windows用户名，由你输入Windows登录密码，不是业务密码或PIN。
重复部署不会重新注册已存在的任务。准备中断保留目录，再次运行用原密码补完。

要让另一台电脑使用同一份业务数据：
  1 在已有订单的主机打开 manage.cmd，选择8“将现有后台设为同步主机”。
    使用原有服务根和业务管理员密码；程序会正常停止、升级后台、保留账本/证书并重启。
  2 在主机选择9“导出加入文件”，保存为新的 .777join 文件（30分钟有效，每台目标电脑一份）。
  3 把本部署包和该加入文件带到目标Windows电脑，打开 manage.cmd，选择10“加入现有数据”。
    选择新的本地业务目录和本机IP，再在文件选择器中选择加入文件。
    下载并验证完整数据后才注册/启动；Windows登录密码仍由你在系统凭证框输入。
    服务数据目录无需共享，也无需安装开发者版或SDK。
  4 两台电脑分别选择11“查看同步状态”。目标节点显示“已同步”及完整数据代；主机显示节点确认代。
    加入完成后可删除一次性文件，运行时不会再次要求它。每台电脑有独立TLS私钥。

只有主机处理订单写入；从机转发业务并异步保存一致副本。保存成功表示主机已落盘，副本随后追赶。
主机断线时从机暂停接单；恢复后自动重连，不会把两份独立账本交替写入。此版本不自动升主或故障接管。
从机不另跑输出任务和每日备份，导出业务仍在主机执行；现有主机备份计划保留。
12“撤销同步节点”需要主机业务管理员密码，会拒绝该节点后续同步和业务转发。
同步按文件复用未变化内容，变化数据库传输完整一致文件；每文件上限256MiB，总清单上限8GiB。

setup.cmd/菜单1仍用于创建独立账本；已有独立账本不合并、不覆盖。要加入请选择菜单10及新目录。
4.23、4.38或其他本机IPv4均可部署；哪台是主机由启用和加入操作决定。
要连接某个节点，在开发电脑最终封包母版/子版时选择该节点生成的公开 connection.json；同一集群使用原有操作员/设备身份。
检查其他电脑时，也可将该公开文件复制到本包目录后双击check.cmd；文件不含私钥、密码或票据。
网络和HTTPS检查不等于业务操作及双位置备份恢复验收。

每次打开创建独立 logs\本次启动文件夹\runtime.jsonl；提权父子及原生准备共用同一会话，有限轮转，不逐次刷轮询日志。
后台运行日志在所选服务根的logs内。退出管理菜单不停止后台。
菜单“正常停止”暂停后台和开机启动；“启动后台”恢复自启。维护前确认后台正常退出。
原host.ps1命令入口仍保留给维护人员；移除任务不删除业务数据。
